# Базовый граф Graphify: публикация и обновление

Основной проект и опубликованный граф: `C:/Users/Mcdos/Desktop/FTS_v13_project/graphify-out/`.
MCP Claude Code и Codex должны читать именно этот `graph.json`.
Временные снимки, кэш, результаты глубокого извлечения и резервные копии хранятся на `E:/`.

Сборка 2026-10-10 продолжает проверенные 82 глубоких пакета из
`E:/Codex/work/fts_graphify_rebuild_20261009_a/`. Завершающий проход —
`finish_20261010/`; воспроизводимый финализатор — `finish_20261010/finalize.py`.
Его входы: исходные глубокие результаты и решения ID, актуальный AST,
дополнительные глубокие пакеты `a`–`g`, действующие канон и слой вопросов.
Пакеты `f`–`g` закрывают найденный при заключительной проверке пропуск PDF cs/0401016v3 (32 страницы).

Порядок слоёв: AST и глубокое извлечение, точный импорт claim_graph/вопросов,
аудиторская навигация, текущие поля канонных карточек. После объединения
сообщества вычисляются один раз; один набор содержательных названий используется
в JSON, HTML, отчёте и метаданных. HTML содержит относительные ссылки на источники.

`graphify_canon_edges.py` и `graphify_audit_navigation.py` принимают
`--project-root` и `--out-dir`; прежние вызовы сохраняются. Канонный инжектор
владеет всеми полями карточек при совпадении ID. Навигационный инжектор
сам создаёт систему якорей из действующих OQ.

`graphify_question_edges.py --project-root ROOT --out-dir OUT` создаёт точный
фрагмент 536 вопросов, 14 групп, 29 объектов, журнала и направленного claim_graph.
Он сохраняет поля `question_origin=assistant_derived`, `author_review=none`,
помечает вопросные связи `INFERRED` и не повышает статусы. Почти-дубли остаются
кандидатами, пока нет содержательного решения. Все вопросы имеют точные адреса
в `QUESTION_CARDS.jsonl`; нерезолвимые определения терминов отмечены явно.

Штатный `manifest.json` создаётся через Graphify `save_manifest` с относительными
путями и хэшами. `build_manifest.json` отдельно хранит покрытие, SHA256 всех входов,
дополнительные структурированные таблицы, происхождение извлечения и ограничения.
Фактические недоступные счётчики токенов записываются как `null`; оценки — отдельно.

Направления, параллельные предикаты и полный состав гиперсвязей доступны в
`finish_20261010/full_raw_extraction.json` на E. Graphify остаётся неориентированной
навигационной проекцией; `work/v14_rebuild/claim_graph/claim_graph.json` сохраняет
авторитетные направленные отношения и статусы. Ограничения проекции перечислены
в `GRAPH_REPORT.md`, `projection_audit.json` и `unresolved_hyperedges.json`.

Перед публикацией проверяются SHA256 входов, уникальность ID и ссылки,
повторное наложение детерминированных слоёв, канон, навигация 31/82/25/20,
согласованность сообществ, запросы MCP и переход из HTML к источнику. При ошибке
проверки опубликованный набор восстанавливается из резервной копии на E.
