- 2026-06-17 — Уточнение «минус из равенства» (ответ на авторский вопрос). `−` ИЗВЛЕКАЕТСЯ
  из `=`, когда форма ЧЁТНА: тождество `F(−x)=F(x)` (напр. `x²=(−x)²`) и есть источник минуса,

  зеркальным окном: Window(F)={F,−F} [ADD_MIRROR_WINDOW; SP_WINDOW «при F≠0 исключение одной
  ветви выбирает другую», derived_constraint]; нулевая граница `F=−F ⟺ F=0` [ADD_ZERO_BOUNDARY/
  SP_ZERO, formal_math_fact]; чётно/нечётная топология [ADDENDUM_V3]. ПОПРАВКА к вчерашнему
  тезису «из `=` минус не получишь»: верен ТОЛЬКО для `=`-предиката (Boolean «a=b?»); `=`-уравнение
  на чётной форме минус ПОРОЖДАЕТ. Источник — симметрия `x↦−x`, равенство её лишь проявляет;
  голый предикат без формы по-прежнему не даёт. NB не смешивать: структурная регенерация минуса
