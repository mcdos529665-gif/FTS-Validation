## 1. Нить А — «сфера→тор» на переходе 6→7 (авторское чтение)

Авторская рамка: **Код (У2, `a=b`) ≈ Шифр** (шифр = биективный код; циклический шифр =
код + сдвиг); **переход 6→7 = внешнее→внутреннее = сфера→тор**.

Математическая спина [внешнее, стандартное]:
- `χ_E(S²)=2`, `χ_E(T²)=0`.
- Сдвинуть сферу без неподвижных точек НЕЛЬЗЯ: у любого `R∈SO(3)` есть ось ⇒ 2 полюса
  (теорема Эйлера о вращении; глубже — Лефшец/Пуанкаре–Хопф, `χ_E≠0`).
- Сдвиги тора СВОБОДНЫ (неподвижных точек нет); `Z/n`, `(Z/n)²` — дискретная
  окружность/тор; модульная арифметика (Цезарь/Виженер) живёт на дискретных торах.
- ⇒ **«свободный циклический сдвиг возможен ⟺ χ_E=0»**: сфера запрещает, тор разрешает.
  Это и есть настоящая связь эйлеровой характеристики с «циклическим шифрованием»
  (в устоявшейся криптографии работает функция Эйлера φ(n) — RSA; χ_E там не используется).

Канон-якоря (почему это не чистая метафора):
- **У6→У7 = `Agg_i(V_i)` → `Close(W,W)`** [CH_06, U_07]: от агрегации по внешней семье
  (индекс i) к САМО-замыканию окна. Склейка-с-собой — операция изготовления
  окружности/тора из отрезка/квадрата: первая нестягиваемая петля.
- Пентада [half_hypothesis §8]: У6 = место 4 (тотализация — «полнота без дыр»),
  У7 = место 5/узел (исчерпание — появляется остаток-петля).
- Канонический крючок топологии уровней: [ADD_PARITY_TOPOLOGY] (чёт/нечёт слои,
  canonical_alignment) и [ADD_TOPO_INVARIANTS] (классы форм по нулям: один / ∞ / нет;
  «e^x требует отдельной boundary/gate»).
- **Сильнейшая сцепка:** `eˣ` (У11) не имеет нулей [C-19]; непрерывное поле без нулей
  возможно только на носителе с `χ_E=0` (Пуанкаре–Хопф; на сфере — «теорема о еже»,
  [внешнее]). Верх лестницы ТРЕБУЕТ `χ_E=0`-геометрии — согласуется с «после 7 — тор».
  Если бы носитель оставался «сферой», форма без нулей на У11 была бы невозможна.
- Нюанс [внешнее]: Энигма гарантировала «буква никогда в себя» — тотализованное
  отсутствие неподвижных точек само стало утечкой (Тьюринг ловил на этом).
  Структурированное отсутствие несёт информацию — привкус `0_A`.

Кандидатные машинные свидетели (В verification.py НЕ внесены):
- T-1: всякое `R∈SO(3)` имеет собственное значение 1 → ось → 2 неподвижные точки на S² (sympy-able).
- T-2: сдвиг тора `(x,y)↦(x+a,y+b) mod 1`, `(a,b)∉Z²` — неподвижных точек нет (тривиально).
- T-3: классы нулей по [ADD_TOPO_INVARIANTS]: `x²/−x²` — один ноль; `cos` — решётка
  `π/2+πk`; `eˣ` — ни одного [C-19] ⇒ мост к `χ_E=0` через Пуанкаре–Хопфа [внешнее].

**Условие поражения (К1):** если «сфера на У6» не получает конкретного носителя
(какое именно пространство и почему), чтение падает в метафору — как отброшенное
«−x²=мнимые числа» [paper §11.2]. Лезвие workflow 2026-07-04 действует и здесь:
«кривая→область»/рост размерности как ход лестницы — нет в артефактах
(У12 канонизирован как замкнутая КРИВАЯ, площадь = analogy_only).

## 2. Нить B — Эйлер / Фурье / Пик / шнуровка (probe P-1…P-4 PASS)

Ни один из четырёх — не рунг; все — считывания/мосты над существующими формами
(дисциплина «регистр ≠ канал ≠ оверлей ≠ уровень», register_map §0):

| Объект | Место в ФТС | Статус |
|---|---|---|
| `e^{i2πft}=cos+i·sin` | мост 10–11, УЖЕ в картине [half_hyp §7] | candidate; спина machine-checked [C-31, C-38–40; P-1] |
| Преобразование Фурье | `Agg_f ∘ мост-Эйлера`: арностный ход «одна гармоника → семья» = O_19 | candidate [P-4] |
| Формула Пика `A=I+B/2−1` | мост «мера из счёта»; **−1 = −χ_E** (общая форма `A=I+B/2−χ_E`) | analogy_only [P-3] |
| Шнуровка Гаусса | знаковое (ориентированное) считывание замкнутой кривой | candidate [P-2] |

Ключевые сцепки:
- **Спектр Фурье раскалывается ровно по канонным каналам:** `|F̂|` (амплитудный
  спектр) = Q-канал — хранит величину, СТИРАЕТ фазу (дословно [C-40]); `arg F̂`
  (фазовый спектр) = Rot. Полярное разложение [C-47] = пара «амплитудный+фазовый
  спектр». [Внешнее эхо: «структура сигнала сидит в фазе» (Оппенгейм) ↔
  «Q-считывание = У6, не выше».]
- **Фурье = диагонализованный СДВИГ:** собственные числа циклического сдвига =
  корни единицы `Z/N` (P-4: `{1,−i,−1,i}` = `Z/4`) — прямое продолжение нити
  `Z/2 ⊂ Z/4 ⊂ U(1)` [half_hyp §7.3] И нити А (свободные сдвиги на торе).
  DFT живёт на `Z/n` — дискретном торе.
- **Phase retrieval** (восстановить сигнал из `|F̂|`) — классическая Фурье-проблема;
  наш D2 sign-retrieval [d2_sign/] — её младшая родня (прогнан, внешне отрицателен).
- **Пик:** поправка `−1` — это `χ_E` внутри школьной формулы (для области с дырками
  `A=I+B/2−χ_E`); мост «мера из счёта»: площадь = подсчёт точек (У6-жест) +
  полграницы + топологическая поправка. Площадь остаётся НЕ-ходом канона.
- **Шнуровка — оправдание решения канона:** (а) знак = ориентация обхода (ось
  «собственной ориентации» У11 [C-21]); (б) замкнутая кривая УЖЕ несёт свою площадь
  как знаковое считывание границы (в пределе — Грин `∮=∬` [внешнее]) ⇒ канон был
  прав, оставив У12 кривой и понизив площадь до analogy_only: диск как объект не
  нужен, площадь = считывание границы.
- **Ответ на «уровни точности» (вопрос автора):** Пик → шнуровка → Грин — один акт
  («содержание из границы») на утончающихся НОСИТЕЛЯХ (решётка → вершины → гладкая
  кривая): движение вдоль оси оверлеев, не вверх по лестнице. Вверх идёт только
  арность: Эйлер (одна гармоника) → Фурье (семья) [O_19].

## 3. Probe (воспроизводимо; запуск 2026-07-04, numpy+sympy, все PASS)

```python
import numpy as np
from math import gcd
from sympy import symbols, exp, cos, sin, I, pi, simplify

# P-1: формула Эйлера с частотой (мост 10-11)
f,t = symbols('f t', real=True)
assert simplify(exp(2*I*pi*f*t) - cos(2*pi*f*t) - I*sin(2*pi*f*t)) == 0

# P-2: шнуровка — знаковая площадь; знак = ориентация обхода
def shoelace(pts):
    x=np.array([p[0] for p in pts],float); y=np.array([p[1] for p in pts],float)
    return 0.5*np.sum(x*np.roll(y,-1)-np.roll(x,-1)*y)
sq=[(0,0),(3,0),(3,3),(0,3)]
assert shoelace(sq)==9 and shoelace(sq[::-1])==-9

# P-3: Пик A=I+B/2-1 (поправка -1 = -chi_E) — брутфорс I по решётке
def on_seg(p,a,b):
    cr=(b[0]-a[0])*(p[1]-a[1])-(b[1]-a[1])*(p[0]-a[0])
    return cr==0 and min(a[0],b[0])<=p[0]<=max(a[0],b[0]) and min(a[1],b[1])<=p[1]<=max(a[1],b[1])
def interior(poly,N=12):
    c=0
    for X in range(-N,N+1):
        for Y in range(-N,N+1):
            if any(on_seg((X,Y),poly[i],poly[(i+1)%len(poly)]) for i in range(len(poly))): continue
            ins=False
            for i in range(len(poly)):
                (x1,y1),(x2,y2)=poly[i],poly[(i+1)%len(poly)]
                if (y1>Y)!=(y2>Y) and X < x1+(Y-y1)*(x2-x1)/(y2-y1): ins=not ins
            c+=ins
    return c
for poly in ([(0,0),(4,0),(0,4)], [(0,0),(3,0),(3,3),(0,3)]):
    A=abs(shoelace(poly))
    B=sum(gcd(abs(poly[(i+1)%len(poly)][0]-poly[i][0]),abs(poly[(i+1)%len(poly)][1]-poly[i][1])) for i in range(len(poly)))
    assert A == interior(poly) + B/2 - 1

# P-4: DFT диагонализует циклический сдвиг; собственные числа = корни единицы Z/4
N=4
F=np.array([[np.exp(-2j*np.pi*j*k/N) for k in range(N)] for j in range(N)])
S=np.roll(np.eye(N),1,axis=0)
D=F@S@np.linalg.inv(F)
assert np.max(np.abs(D-np.diag(np.diag(D))))<1e-9   # диагонально
# diag(D) ≈ {1, -i, -1, i} = Z/4  — нить корней единицы [C-38/39]
```
