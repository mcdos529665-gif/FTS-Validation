# Покарточный поиск альтернатив для принятых 2026-10-18 карточек

Основание: вопрос `oq-canon-no-alt-per-card-reason`. Решение автора 2026-10-20:
покарточную запись делать только для карточек, где альтернативу найти легче всего;
сначала отбор. Статусы здесь не меняются. Выводы ниже — оценка ассистента, не
авторское решение.

## Отбор

Рассмотрены 64 карточки со слоем `card` и решением `canonical` в
[dispositions_2026-10-18.tsv](dispositions_2026-10-18.tsv). В отбор попала карточка,
у которой в артефактах есть хотя бы один след возможной альтернативы:

1. её id назван в причине или области строки таблицы с решением, отличным от
   `canonical` (`alternative`, `conflict`, `superseded`, `historical`);
2. её id назван в открытом пункте `work/OPEN_QUESTIONS.md` (`- [ ]`);
3. её id назван в записи `work/REFUTED.md`.

Отобрано 10 карточек: `A_07`, `M_07`, `CHI_CARRIER`, `U_07`, `U_12`, `O_20`,
`CHI_LADDER_U9`, `M_12`, `O_14`, `O_19`. У остальных 54 следов по этим трём источникам
нет; это значит «не найдено в проверенных источниках», а не «альтернативы нет».
Поиск вне этих источников (внешняя литература, неоформленные идеи) не проводился.

## Записи

Формат: где найден след → что это → вывод.

### `A_07`
- След: строки `CP-127` (`conflict`, H1: `T₂k=−I` противоречит A_07), карточки
  `CHI_LADDER_U7` и `COMPLEX_LADDER_U7` (`conflict`, старая ветвь `−χ²`/`−Q` с `!=` не
  согласована с A_07, нужен мост).
- Разбор: `CP-127` — внешнее предложение другой модели, «не принято автором»;
  `CHI_LADDER_U7` и `COMPLEX_LADDER_U7` — соседние карточки, а не запись того же
  объекта. Конкурирующей формулировки самой A_07 в той же области нет.
- Вывод: альтернативы той же области не найдено; открыта несовместимость соседних
  записей с A_07 (мост не построен). Для A_07 это не препятствие, для соседей остаётся.

### `M_07` — найдена именованная альтернатива
- След: `CP-094` (`alternative`): «Краткая `R=B∨D` против действующей M_07;
  пригодность минимума открыта». REFUTED 2026-09-25: простая `S_7` не совпадает с M_07,
  а является её правой ветвью.
- Разбор: `CP-094` прямо названа кандидатом на краткую M_07, не принята автором, выбор
  между записями не сделан. Для M_03 тот же случай (`CP-092`, «минимальная M_03 против
  действующей развёрнутой записи») в таблице отнесён к `alternative`, а карточки
  `M_08…M_11` оставлены без принятия из-за `CP-095`. Для M_07 решение обратное.
- Вывод: **открытая именованная альтернатива есть**, причина «нет открытого
  конкурирующего варианта» к M_07 не подходит буквально. Если `CP-094` — запись другого
  регистра (краткая форма рядом с развёрнутой), нужна явная пометка об этом.
  **Решение автора 2026-10-20:** `CP-094` относится к другому регистру (краткая форма
  рядом с развёрнутой); принятие `M_07` сохраняется (`oq-canon-m07-chi-carrier-open-alternative`).

### `CHI_CARRIER` — найдена именованная альтернатива
- След: `CP-104` (`alternative`): «Один из возможных паспортов χ; не выбран вместо
  действующего `CHI_CARRIER`». В «Основных вариантах» CANONIZATION отдельно названа
  нормировка χ.
- Разбор: `CP-104` не принята автором и не отвергнута; нормировка χ в ФТС не
  восстановлена. Карточка принята как точная запись текущего паспорта.
- Вывод: **открытая именованная альтернатива есть** (тот же вопрос, что для M_07).
  **Решение автора 2026-10-20:** `CP-104` относится к другому регистру; принятие
  `CHI_CARRIER` сохраняется.
