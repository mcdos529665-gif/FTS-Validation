## 0. Генезис −1 — назван, не определён (отдельно от колонки)

Авторская трудность (точная формулировка): нельзя формально определить уровень,
который должен быть неформализуем.

Разрешение: **формализуются не содержание −1, а его НЕХВАТКИ.**

- −1 = `a≈□` (OpenPlace): сырая открытость, пара ещё не возникла; носитель —
  пред-носитель [лист 28, строка 1: «pre-carrier genesis»].
- Формальная подпись: −1 — **единственный** уровень БЕЗ правой части, БЕЗ нулевой
  границы, БЕЗ зеркального окна [лист 06, строка −1: «—», «—», «pre-window»]. У всех
  уровней ≥0 есть `F = ⊖F ⟺ F = 0` [C-01]; у −1 нет формы `F`, которую можно
  отрицать или обнулить.
- Поэтому «−1» определён как «уровень, лишённый всех формальных рукоятей». Любая
  определённая формула для −1 была бы **Tot** (тотализация), стирающим его
  открытость; сам канон отказывается дать −1 определённую форму (M_m1 = `a≈□?`).
- Связь с фундаментом §6.0 статьи: −1 — ДО `a=a` (первой определённости / мета-аксиомы);
  генезис пред-формален.
- Условие поражения (D0): если предъявлена определённая формализация −1 БЕЗ Tot (без
  стирания открытости) — генезис формализуем, раздел падает. Пока: канон сам не даёт
  −1 определённой формы.

Итог: −1 формализуется КАК неформализуемое — через отсутствие рукоятей, не через
содержание. Поэтому он вне колонки.

## 1. Колонка неопределённости: node+1 = {0, 4, 8, 12}, шаг +4

Неопределённость как **содержание** уровня (удержанная/поставленная неразрешённая
пара) повторяется на `node+1` (узлы при −1, 3, 7, 11) и **эскалирует по типу**:

| У | Форма | Тип неопределённости | Где живёт | Свидетели |
|---|-------|----------------------|-----------|-----------|
| 0 | `a≠a` | противоречие (норма/отклонение слиты до У1) | в ℝ | M_00; C-01 |
| 4 | `\|x\|`, `(a=b)∧(a≠b)` | вещественное поле `{x,−x}` (знак открыт) | в ℝ | M_04; C-03/C-04 |
| 8 | `√`, `?(С)` | ветвь: восстановление **выходит из ℝ** (нужен `i`) | вне ℝ | M_08; C-06/07/09; COMPLEX_LADDER_U8 |
| 12 | `x²+(y−2)²=4` | отношение: две функц-ветви, **не функция** | вне класса функций | M_12; C-23/C-24 |

Эскалация (проверяемая): **остаётся в ℝ (4) → выходит из ℝ (8) → выходит из класса
функций (12).** Каждый «полушаг» — другого рода.

Микроструктура окна: `node+1` ДЕРЖИТ/СТАВИТ пару → `node+2` РАЗРЕШАЕТ.
У4 `∧` (держит) → У5 `∨` (выбирает, `Select`); У8 `?` (спрашивает) → У9 куб
(возвращает знак, [C-11]). Это та же +2-проекция [О8].

## 2. «Половина_А» — случай У8 (ветвевой полушаг). «8+» ОПРОВЕРГНУТО (D1)

Вчерашнее «половина = 8+» **опровергнуто**: знаковый полушаг (`{x,−x}`,
величина-есть/знак-открыт) предъявим уже на У4, на ℝ.

Уточнение: У8 — не «начало половины», а её **ветвевой род** (`√`, нужен `i`);
знаковый род — уже У4; реляционный — У12. «Половина_А» переобъясняет предположение
острее §7.2: гипотеза = `{A, ⊖A}` как **вопрос** (ветвь отложена), а не «слабое A».

## 4. Машинные свидетели (кандидатные; `verification.py` не тронут)

| ID | Утверждение | Статус |
|----|-------------|--------|
| H-4 | У4 `\|x\|=2` → две веществ. ветви `{−2,2}` (знак открыт, в ℝ) | PASS |
| H-8a | У8 обратить квадрат при <0 → нет веществ. корня (выход из ℝ) | PASS |
| H-8b | `i` — полуповорот: `i²=⊖`, `(e^{iπ/2})²=−1` | PASS |
| H-8c | `√` делит фазу: `(√r·e^{iθ/2})² = r·e^{iθ}` | PASS |
| H-12 | У12 при x=0 → два `y` `{0,4}`: отношение, не функция | PASS |
| H-res | У9 куб возвращает знак, стёртый У6/отложенный У8 | PASS |
| H-u8 | У8 — единственная дробная ступень: `√\|x\| = \|x\|^{1/2}` | PASS |
| H-col | колонка = `node+1` = `{0,4,8,12}`, шаг +4 | PASS |

Probe (воспроизводимо; при канонизации — перенести в `verification.py` как C-60…):

```python
import sympy as sp
from sympy import I, sqrt, Abs, sign, exp, pi, symbols, solveset, S, Eq, simplify, Rational
x, y, t = symbols('x y t', real=True)
rr = symbols('rr', positive=True); th = symbols('th', real=True)
def chk(cid, ok, claim): print(("PASS" if ok else "FAIL"), cid, "-", claim)

chk("H-4",  solveset(Eq(Abs(x),2), x, S.Reals) == sp.FiniteSet(-2,2),
    "U4 |x|=2 -> two real preimages (sign open, stays in R)")
chk("H-8a", solveset(Eq(t**2,-1), t, S.Reals) == S.EmptySet,
    "U8 invert square at <0 -> no real root (leaves R)")
chk("H-8b", simplify(I**2+1)==0 and simplify(exp(I*pi/2)**2+1)==0,
    "i is the half-turn: i^2 = mirror; (Rot_{pi/2})^2 = -1")
chk("H-8c", simplify((sqrt(rr)*exp(I*th/2))**2 - rr*exp(I*th))==0,
    "sqrt halves phase: (sqrt(r) e^{i th/2})^2 = r e^{i th}")
chk("H-12", solveset(Eq(0**2+(y-2)**2-4,0), y, S.Reals) == sp.FiniteSet(0,4),
    "U12 circle at x=0 -> two y: relation, not a function")
chk("H-res", all(sign(v**3)==sign(v) for v in (-2,-1,1,2)),
    "U9 cube restores sign erased by U6 / deferred by U8")
chk("H-u8", simplify(sqrt(Abs(x)) - Abs(x)**Rational(1,2))==0,
    "U8 = unique fractional rung sqrt|x| = |x|^(1/2)")
col=[n+1 for n in (-1,3,7,11)]
chk("H-col", col==[0,4,8,12] and all(col[i+1]-col[i]==4 for i in range(3)),
    "indeterminacy column = node+1 = {0,4,8,12}, step +4")
```

## 5. Как проверять (К1–К5)

- **К1 — свидетели:** §4 (8 PASS). При канонизации → C-60… в `verification.py`.
- **К3 — гардрейлы:**
  - колонка = **ровно `node+1`** (0,4,8,12), НЕ все уровни; определённые (1,2,3,5,6,9,10,11) — вне;
  - **−1 ≠ колонка** (генезис, пред-формален, §0);
  - половина ≠ фаза Д10 (двузначная ветвь ≠ непрерывный угол) ≠ −A (определена) ≠
    branch-access (оператор, не состояние) ≠ 0_A/¬A (те определённы);
  - типы **провабельно различны** (ℝ-fold ≠ нужен-`i` ≠ не-функция) — иначе декоративно.
- **К5 — условия поражения:**
  - **D0** — формализация −1 без Tot (§0).
  - **D1 (СРАБОТАЛО)** — «8+ only» опровергнут: половина уже на У4.
  - **D2 (главный риск)** — если «Половина_А» не даёт роли сверх `COMPLEX_LADDER_U8` —
    переименование (провал F3 / QuestionGain O_14).
  - **D3** — если типы колонки сводимы друг к другу — декоративна (но провабельно различны).
  - **D4** — не-колоночный уровень с той же неопределённостью-как-содержанием, ИЛИ
    колоночный, оказавшийся определённым — колонка падает.
- **Решающий операциональный тест (род У8):** **phase / sign retrieval** (восстановить
  `x` из `|x|`) — внешний якорь, если рамка «Половина_А» даёт то, чего не даёт плоский
  `¬A` (рядом с Blackwell/closure из §13 статьи).
