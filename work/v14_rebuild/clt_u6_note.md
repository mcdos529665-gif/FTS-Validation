## 1. ЦПТ — не «пример», а теорема Ч-регистра У6

Каждый элемент ЦПТ ложится на канонный элемент У6:

| Элемент ЦПТ | Элемент У6 (канон) | Probe |
|---|---|---|
| условие теоремы: конечная дисперсия | существование **`V·V`** — М-регистр как гипотеза теоремы | C-4 |
| семья слагаемых `i` | арностное требование `Agg_i` [O_19] — **условие уточняет §2** | C-5 |
| что выживает при Agg+масштаб: ровно `σ²t²`-член лог-хар. функции | **`x²`** — А-форма как *инвариант потока агрегации* | C-1 |
| универсальность (источник забыт, все → Гаусс) | **тотализация** (место 4 пентады: «покрыть всё, скрыв остаток») | C-3 |
| скорости стирания: `x³`~`1/√n`, `x⁴`~`1/n` (кумулянты, `n^{1−r/2}`) | **буквализация О2**: Tot уничтожает ≠-материал — теперь с формулой | C-2 |
| аттрактор = неподвижная точка агрегации | самовоспроизводство тотализованной формы | C-1 |
| отказ теоремы: нет `V·V` (Коши) → агрегат не сжимается (пороги точны для симметричных устойчивых законов: α=2 — нет второго момента, α≤1 — среднее не сходится; вне класса — критерий Феллера [внешнее]; G60-39) | **условие поражения**: без своего минимума У6 не тотализует (мир Леви) | C-4 |

Сцепки с уже записанным:
- **Фурье [topo_chi_note §2]:** доказательство ЦПТ идёт в Фурье-регистре (свёртка →
  умножение); Гаусс — неподвижная точка и агрегации, и самого Фурье. Двойной fixed point.
- **«6+ по масштабу» [C-50/51]:** ЦПТ — теорема о пределе при перемасштабировании
  (`/σ√n`); первый «масштабный» уровень получает своей теоремой ренорм-предел.
- **Чётность [C-05]:** первым умирает нечётный `x³` (знаковая асимметрия, `1/√n`),
  потом чётный `x⁴` (`1/n`) — агрегация стирает знаковое раньше модульного (curiosity).
- **Лицензия χ²-точки канона:** «У6 = χ²» [C-54, strong_statistical_analog] молчаливо
  опирается на ЦПТ (χ²-тест валиден, потому что остатки χᵢ ≈ гауссовы ПО ЦПТ).
- Curiosity (не тянуть): аттрактор `e^{−x²/2}` — композиция форм У11∘У7; лестница
  предельных теорем ЗБЧ(`x`)→ЦПТ(`x²`)→Эджворт(`x³,x⁴`) идёт по степеням А-регистра.

## 2. Поправка Маркова к условию семьи (исправление строки таблицы §1)

Первая версия таблицы требовала «независимую семью i». **Это некрасовская ошибка** —
и Марков её опровергает: ЗБЧ/ЦПТ выживают на *зависимых* цепях (при эргодичности/
перемешивании). Правильное условие У6-тотализации: **не независимость, а достаточное
внутреннее забывание семьи** (mixing). [внешнее, стандартное]

Probe C-5 (цепь с автокорреляцией 0.8 — сильная зависимость):
- C-5a: lag-1 автокорр = +0.800 — независимости НЕТ;
- C-5b: среднее → 0.5 — ЗБЧ работает и без независимости;
- C-5c: блочные суммы → гауссов аттрактор (skew −0.007, kurt−3 −0.043) — ЦПТ работает;
- C-5d: `n·Var(среднего)` = 2.225 (теор 2.25 = 0.25·(1+λ)/(1−λ); iid дало бы 0.250) —
  **вся структура связи выжила в агрегате как ОДИН скаляр** (инфляция дисперсии ×9),
  причём скаляр дисперсионного — `V·V` — уровня. Форма связи стёрта.

Самая острая формулировка: агрегат хранит о структуре семьи ровно одно число V·V-рода;
всё выше — стёрто со скоростью `n^{1−r/2}`.

## 3. Кейс Марков–Некрасов (ретродикция, эталонный «кейс разведения»)

История [внешнее]: Некрасов (~1902): «социальная статистика регулярна» + «ЗБЧ требует
независимости» ⇒ «акты независимы» ⇒ «независимость = свобода воли» (далее — богословие).
Марков (1906): цепи ЗАВИСИМЫХ величин с выполненным ЗБЧ ⇒ посылка необходимости ложна ⇒
вывод рушится. 1913: демонстрация на 20 000 букв «Онегина» — заведомо зависимый источник
с идеально устойчивыми частотами.

Разбор по лестнице (авторская посадка уровней: У4=Вероятность, У5=Выбор, У6=Статистика;
уточнение механизма — ниже):

**Две склейки Некрасова:**
1. **Ложный синоним поперёк регистров: «независимость = свобода воли».**
   Независимость — структурный факт СЕМЬИ `i` (условие на вход `Agg_i`);
   свобода — семантика ВЫБОРА (У5, `Select`). Склеены факт о корреляциях и факт об агенте.
2. **Незаконный спуск У6→У5: читать по тотализованному агрегату стёртое.**
   ЦПТ/ЗБЧ — теоремы о забывании; бассейн аттрактора широк (и независимые, и зависимые
   семьи). Некрасов принял широту бассейна за свидетельство о начальной точке.
   Анти-мода У6: «статистика как ответ» [гард G_CHI] + ложное повышение [лист 04] —
   статистический факт повышен до метафизического.

**Ход Маркова = ФТС-паттерн фальсификации, выводимый из диагноза:** если ошибка —
склейка «регулярность ⇒ независимость», то разрушающий ход — предъявить семью БЕЗ
независимости с ТОЙ ЖЕ регулярностью. Ровно это и есть цепь Маркова (probe C-5 —
машинная форма). Тип контрпримера выводится из типа ошибки — поэтому кейс проходит
критерий «различающего хода» (§4). Уточнение к посадке «Марков бьёт через У6»:
командовать У6 (знать, о чём статистика свидетельствует и о чём молчит) — это У7-акт
(`Знание` = честное закрытие окна) против некрасовского ложного закрытия.

**Симметричный гард:** Марков доказал СЛЕПОТУ У6 к У5 — не отсутствие свободы.
Регулярность даёт `0_свидетельства` о воле, а не `¬воля` (дословно `¬A ≠ 0_A`).
Из У6 не следует ни богословие Некрасова, ни атеизм Маркова. ФТС строже обоих.

**Мораль (производительность разведения):** правильно разведённый ложный синоним
породил инструмент, переживший спор, — цепи Маркова (сегодня: MCMC, PageRank).

## 4. Жанр «кейсы разведения» — кандидат внешней площадки ФТС

Авторский мета-тезис (2026-07-04): главная работа ФТС — разведение ложных синонимов и
наведение неложных мостов; скорость нахождения нитей в сессиях — свидетельство
продуктивности грамматики. Следствие: естественная внешняя площадка ФТС — не
ML-бенчмарки (0/2: o20, D2 — информационная эквивалентность), а **разбор понятийных
споров**: грамматика доказывает себя разбором предложений, включая знаменитые
неправильные.

**Критерий засчитывания кейса (обязателен, анти-QuestionGain):** разбор обязан
порождать РАЗЛИЧАЮЩИЙ ХОД (какой контрпример строить / какие данные решают спор),
а не только переименование позиций. Кейс Марков–Некрасов проходит: тип контрпримера
(зависимая семья с той же регулярностью) выводится из типа ошибки (склейка
«регулярность⇒независимость»). Кейс без различающего хода не засчитывается.

Статус жанра: candidate; каждый кейс — ретродикция (К4), пока разбор не сделан ДО
разрешения живого спора (это была бы К1-заявка). Смежное направление — Blackwell-слой
(§13 статьи: ФТС ↔ статистическая теория решений).

## 5. Probe (воспроизводимо; запуск 2026-07-04, numpy+sympy, все PASS)

```python
import numpy as np
from sympy import symbols, exp as sexp, sqrt as ssqrt, simplify
rng = np.random.default_rng(20260704)

# C-1: Гаусс = неподвижная точка Agg+масштаб (хар. функция / Фурье-регистр)
t = symbols('t', real=True); phi = sexp(-t**2/2)
assert simplify(phi.subs(t, t/ssqrt(2))**2 - phi) == 0

def skew_kurt(x):
    x = (x - x.mean())/x.std(); return float((x**3).mean()), float((x**4).mean()-3)

# C-2: скорости стирания выше-x² (exp(1): skew=2/sqrt(n), kurt-3=6/n; кумулянты складываются)
for n in (1,4,16,64):
    g1,g2 = skew_kurt(rng.exponential(1,(100000,n)).sum(axis=1))
    # n=64: skew +0.248 (теор 0.250), kurt-3 +0.060 (теор 0.094)

# C-3: универсальность: uniform/bernoulli/exponential, n=256 -> skew,kurt-3 ≈ 0/0

# C-4: defeat: Коши (нет V*V): IQR(среднего n Коши) = 2.0 при ЛЮБОМ n — не сжимается
for n in (1,100):
    m = rng.standard_cauchy((100000,n)).mean(axis=1)
    # IQR ≈ 2.0 и при n=1, и при n=100

# C-5: поправка Маркова: цепь (P_stay=0.9, λ=0.8) — зависимость есть, аттрактор тот же
p_stay, N, n_blk = 0.9, 2_000_000, 1000
lam = 2*p_stay-1
flip = (rng.random(N) >= p_stay); flip[0]=False
x = (np.cumsum(flip) % 2).astype(float)
# (a) corr(x[:-1],x[1:]) ≈ +0.800  (b) mean ≈ 0.5  (c) блочные суммы: skew/kurt ≈ 0/0
# (d) n·Var(среднего) ≈ 2.25 = 0.25·(1+λ)/(1−λ)  — след связи = ОДИН V·V-скаляр (×9)
```

Итоги прогона: C-1 PASS · C-2 ставки подтверждены (n=64: 0.248/0.250; 0.060/0.094) ·
C-3 все ≈0/0 · C-4 IQR 2.007/1.996 (не сжимается) · C-5 a=+0.800 b=0.4989
c=(−0.007/−0.043) d=2.225 (теор 2.25).
