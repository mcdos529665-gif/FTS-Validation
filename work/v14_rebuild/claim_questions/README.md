# Карточки вопросов к утверждениям (рабочий слой)

Файл `QUESTION_CARDS.jsonl`: по одной карточке на каждое утверждение, у которого
есть текст, — 285 карточек: 172 карточки канона (`source/fts_cards.jsonl`),
37 исследовательских утверждений, 25 групп проверок аудита, 20 находок аудита,
31 паттерн.

Проверки (62 шт., `verification*.py`) не включены: это тесты, а не утверждения.

## Поля

- `question_id`, `source_id`, `source_kind`, `source_status` — ссылка на исходное
  утверждение и его статус на момент выгрузки (статус не меняется).
- `source_text` — начало текста утверждения (до 200 символов).
- `question` — вопрос, на который утверждение отвечает.
- `question_origin: assistant_derived` — вопрос сформулирован ассистентом по тексту
  утверждения. Это не авторская постановка и не принятый вывод.
- `answer_status: unanswered` — ответов здесь нет.
- `author_review: none` — авторской проверки формулировок не было.

## Что не сделано

- Ответы не записаны. Вопрос отделён от ответа намеренно.
- Вопросы не привязаны к `OPEN_QUESTIONS.md` и не добавлены в `claim_graph`:
  это потребовало бы пересборки графа и решения автора о связи.
- Формулировки вопросов не проверены по существу; часть вопросов — переформулировка
  целей утверждения, а не отдельный открытый вопрос.
- Статусы утверждений не менялись (правило К1–К5 и SP_*).

## Как пересобрать

Вопросы лежат в `QUESTION_CARDS.jsonl`; при изменении формулировок меняется только
этот файл. Покрытие проверено: 285 утверждений ↔ 285 вопросов, пропусков и дублей нет.
