# У0: вычислительный пример NaN != NaN

Дата: 2026-10-19. Происхождение: пояснение составителя по вопросу пользователя.
Статус: [внешнее], вычислительная иллюстрация. Канон, авторское принятие и St_FTS не меняются.

## Точная связь с записями ФТС

В каноне M_00 записано `a≠a`, а CH_00 задаёт операциональное чтение `Eq₀(a,a)=false`.
Вычислительное сравнение ниже показывает конкретную операцию, при которой сравнение значения с самим собой возвращает ложь. Соответствие этой операции всей семантике U_00 не установлено.

## Проверяемый пример

```python
a = float('nan')
print(a == a)  # False
print(a != a)  # True
```

Живой результат при подготовке записи: {"a == a": false, "a != a": true}.
Основание внешнего поведения: [официальная документация Python, math.nan](https://docs.python.org/3/library/math.html#math.nan).

## Область и ограничения

Речь идёт о NaN в вычислениях с плавающей точкой и операции числового сравнения. Не утверждается, что обычное действительное число не равно самому себе, что нарушено логическое тождество объекта или что NaN определяет всю сущность У0. Сравнение значений и тождество объекта различаются. Эта иллюстрация не отождествляет NaN со структурированным отсутствием 0_A: смысл 0_A требует собственных оснований A2 и исследования механизмов отсутствия.
