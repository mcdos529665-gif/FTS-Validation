## Проверки идентичности и ограничения

- Semantic Scholar вернул HTTP 429 на первом DOI; дальнейшие запросы остановлены. S2_METADATA.json хранит ответ. Независимая S2-верификация этой выборки не завершена; для основных публикаций использованы DOI и первичные страницы/тексты.
- Поиск Undermind вывел сомнительную запись Gre15 с 2015 годом для *Provenance Semirings*. Она не включена как отдельная работа. Оригинал S3 — 2007 год, три автора, PODS; lookup по правильному DOI не разрешился, первичный PDF доступен.
- Читатель PDF S1 спутал cite key рабочего пространства Cha25c со ссылкой Cha25c внутри библиографии статьи. Используется идентичность S1 по титулу/DOI Cambridge; чужая работа о memory models не приписывается целевой статье.
- Wal92 (*The pth Root of an Analytic Function*) доступна только как метаданные/аннотация и не служит основанием нового доказательства. Предложение TA1 ниже — явно наша спецификация.
- S5 не доказывает тезис «никакое наблюдение не различает a и a⁻¹». В отчёте речь только о данных расщепления в промежуточных полях абелева расширения; дополнительные инварианты могут различать элементы.
- Алгебраические доказательства и конечные свидетели в REVIEW — самостоятельные вычисления этого пакета. Внешние источники не устанавливают авторское принятие или St_FTS.
