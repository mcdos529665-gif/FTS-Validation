# WF-107 — относительный знак, 2026-10-06

Claim: `WINDOW_RELATIVE_SIGN_PROBE`; адрес `oq-window-family-roles`.
Навык `fts-wolfram-audit`. Механический шаг делегирован; оценка основного
агента: **confirmed_math** для следующего точного предиката.

Область: `s,t∈R`; конечная специализация `s,t∈{−1,+1}`. Для всех s,t
`((s+t)²−(s−t)²)/4=st`; общая смена обоих знаков сохраняет значение.
На четырёх знаковых парах два квадрата равны `(4,0)` при s=t и `(0,4)`
при s=−t. Предположения непусты. Опровержение: вещественный контрпример
тождеству или несовпадение одной из четырёх строк. Норм-мультипликативность,
смысл ФТС и таблицы алгебр в предикат не включены.

Local check: `relative_sign_probe.py`, четыре пары знаков; применение к
сохранённым таблицам восьми моделей проверяется отдельно локально.
Связь с прежними C-NN: это скалярная поляризация из C-68/C-70 с новым
кандидатным использованием в сравнении путей.

Один context (14.049 с, нерелевантные справочные фрагменты; не доказательство),
один evaluator (4.572 с, timeConstraint=20), всего 18.621 с. Повторов нет.

Полный выполненный код:

```wl
ClearAll[s,t];
p=((s+t)^2-(s-t)^2)/4==s*t;
nonempty=Resolve[Exists[{s,t},s==1&&t==-1],Reals];
universal=Resolve[ForAll[{s,t},p],Reals];
violation=Reduce[Not[p],{s,t},Reals];
witness=FindInstance[Not[p],{s,t},Reals];
flip=Expand[((-s-t)^2-(-s+t)^2)/4-((s+t)^2-(s-t)^2)/4];
rows=Flatten[Table[{s,t,(s+t)^2,(s-t)^2,((s+t)^2-(s-t)^2)/4},{s,{-1,1}},{t,{-1,1}}],1];
InputForm[{nonempty,universal,violation,witness,flip,rows}]
```


Непустота и универсальное тождество подтверждены; Reduce нарушения — False;
FindInstance — пустой список; разность после общей смены знака — 0.
Нуль s или t допускается в универсальном полиноме, знаменатель — константа 4.
Область знаковых единиц исключает нулевой базисный результат отдельно.
Контрпример не найден; доказательный результат — универсальный Resolve,
а не само по себе отсутствие найденного примера.
