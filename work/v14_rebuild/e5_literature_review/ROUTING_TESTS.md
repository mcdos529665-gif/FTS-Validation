# Routing acceptance cases

| Запрос | Ожидаемое поведение | Результат статической проверки |
|---|---|---|
| «Проведи систематический обзор для `oq-systematic-literature-review`» | Только совет вызвать `$fts-academic-research` с режимом | PASS: advisory gate, implicit=false |
| «Это мировая новизна ФТС?» | Только совет; требовать bounded novelty | PASS: gate + protocol |
| «Проверь карточку U_07 в локальном каноне» | Не советовать ARS | PASS: явное исключение |
| «Исправь опечатку в статье» | Не советовать ARS | PASS: явное исключение |
| «Есть ли строка в экспортном файле?» | Не советовать ARS | PASS: явное исключение |
| «Докажи точную формулу с главной ветвью» | Советовать только `$fts-wolfram-audit` | PASS: раздельный маршрут |
| «Публикация повышает статус ФТС» | Советовать ARS, но запретить автоповышение | PASS: no-smuggling + SP/K1-K5 gate |

Навык `fts-academic-research` не допускает implicit invocation. Полный ARS runtime,
автоматические agent-команды и hooks не включены.
