# DR-09 · [O_09] Независимая альтернатива M′

**Академический исследовательский отчёт. Дата поиска и проверки: 10 сентября 2026 года, UTC.**

Объект: локальная ФТС из предоставленного исследовательского пакета. Статус документа: внешний аудит производных утверждений; канон не изменён. «Связность», «отсутствие», «знание», «уровень» и «стоимость» ниже не получают автоматически общеупотребительного математического значения.

## Найдено → зависимости → вывод → что не закрыто

### Найдено

1. **Независимая локальная M′ существует.** Для конечной системы переходов и заранее фиксированного языка наблюдений её можно построить как наиболее грубое разбиение, сохраняющее все наблюдения. Носитель, переходы, предикаты и алгоритм уточнения задаются без уровней или аксиом ФТС. Основной внешний результат — generalized strong preservation у Ранцато—Таппаро; независимая конечная конструкция и проверяемый пример приведены ниже. [R1](https://arxiv.org/html/cs/0401016v3)
2. **Один общий формализм способен выразить несколько нужных функций, но выразимость не равна экономной замене всей ФТС.** Abstract interpretation — наиболее сильный кандидат на общий аппарат сохранения наблюдений и композиции абстракций. Блэквелл сравнивает статистические решения; достаточные статистики — сохранение параметрической информации; причинные состояния — прогноз; FCA — классификацию и импликации; информационные порядки — наблюдаемость; state abstraction — поведение относительно заданной модели решений. Это разные проверяемые функции, а не новые названия уровней ФТС.
3. **Необходимость единственного пути, универсальная решётка и минимум полной стоимости из этих результатов не следуют.** Получены конечные свидетели разных путей к одному минимальному представлению, отсутствия динамически согласованного сечения у бисимуляционного фактора, сохранения статистического решения при потере истории и экспоненциального размера полного пространства понятий. Для общего порядка Блэквелла отсутствие решётки установлено внешней теоремой. [R5](https://arxiv.org/pdf/1401.3146)
4. **Точный результат вычислительной проверки:** перебраны все 203 разбиения шестисостоянийной системы; четыре удовлетворяют выбранному условию стабильности и сохранению метки; единственный минимальный фактор имеет четыре состояния. Это проверка независимого математического примера, а не прогон реализации ФТС.

### Зависимости

Решающий мост имеет вид:

\[
\text{операциональный фрагмент ФТС}
\xrightarrow{\text{явная интерпретация}}
(\Sigma,R,\mathcal L,\mathrm{Obs})
\xrightarrow{\text{сохранение наблюдений}}
M'.
\]

Нужно отдельно зафиксировать: какие входы и вмешательства допускаются; какие ответы наблюдаемы; что значит одинаковый ответ; включает ли наблюдение происхождение данных, тип отсутствия и отказ; какие операции учитываются в цене; какая разновидность связности проверяется. Если мост не построен, сходство с ФТС остаётся `analogy`.

### Вывод

**Вердикт DR-09: `independent_alternative` для конечного операционального фрагмента; `insufficient_evidence` для полной замены ядра −1…7 с не большей C(E).**

При сравнении конечных детерминированных представлений, где текущее абстрактное состояние полностью определяет ответы на фиксированный язык, M′ ниже минимальна по числу различимых состояний. Поэтому любое представление ФТС из того же класса, сохраняющее эти ответы, имеет не меньше состояний. Это условная теорема о чётко заданной проекции. Она не устанавливает меньшие затраты на построение, код, память всей системы или все компоненты C(E).

O_09 можно сохранить как требование честного аудита. Его нельзя использовать как уже выполненное доказательство незаменимости ФТС. Обратное утверждение — «Ранцато—Таппаро уже заменяют всю ФТС» — также не подтверждено.

### Что не закрыто

- Полная операциональная семантика сравниваемого фрагмента ФТС, особенно начальной сцены и кандидатного ядра У7.
- Общий, заранее установленный порядок сравнения C(E), правила распаковки и независимый учёт стандартных операций.
- Исполняемая ФТС и набор обязательных тестов: в материалах есть канон, схемы и открытые задачи, но не завершённая сопоставимая реализация для настоящего F3-прогона.
- Перенос сохранения внешних наблюдений на все локальные основания связности O1–O8. Такой перенос требует отдельных мостов.
- Статистическая проверка на реальных данных с пропусками и происхождением данных. В этом отчёте выполнены точные конечные проверки, а не такой эмпирический эксперимент.
- Полнота проверки исправлений: проведён целевой поиск уведомлений и проверены доступные записи/версии; закрытые полные тексты и недоступные издательские панели не позволяют утверждать отсутствие любых исправлений во всех базах.

### 2.3. Нейтральный контракт сравнения

Предлагается фиксировать до запуска

\[
\mathcal B=(D,\mathcal I,\mathcal J,\mathcal L,\mathrm{Obs},\varepsilon,\mathcal C,\mathcal A).
\]

Здесь D — область данных; I — входы; J — допустимые вмешательства; L — наблюдения/вопросы; Obs — правило чтения результата; ε — точное равенство либо допустимая погрешность; C — цена; A — явно оплаченные предпосылки. Для точного конечного примера ε=0.

Модели эквивалентны в этом контракте, если

\[
\forall i\in\mathcal I\;\forall j\in\mathcal J\;\forall\varphi\in\mathcal L:\quad
\mathrm{Obs}_{FTS}(i,j,\varphi)=\mathrm{Obs}_{M'}(i,j,\varphi).
\]

Для случайных моделей вместо равенства отдельных реализаций требуется выбранное равенство распределений или рисков. Это не взаимозаменяемые определения.

Независимость M′ означает, что её вывод не использует канонический порядок ФТС, обязательность её уровней или их специфические отношения как посылки. Использование множества, равенства, выбора или агрегации само по себе не устанавливает «скрытую ФТС». Эти операции должны оплачиваться; доказательство того, что они уже логически влекут всю структуру ФТС, было бы отдельным содержательным результатом. Иначе критерий независимости запрещает любую альтернативу по определению, что противоречит собственной мотивировке O_09.

## 4. Независимая M′ из направления Ранцато—Таппаро

Точная опорная конструкция R1: AD_L=Moore({⟦φ⟧ : φ∈L}), то есть замыкание денотаций по произвольным пересечениям. Thm 5.8 утверждает A∈SP_L ⇔ A⊑AD_L в авторском порядке точности. Для унарного f forward completeness имеет вид fμ=μfμ, μ=γα; это условие нельзя без оговорок заменить SP (Example 6.6). В конечном примере ниже замкнутость реализуется явно. [R1, §5.2 и §6](https://arxiv.org/html/cs/0401016v3)

### 4.1. Посылки без ФТС

Возьмём конечное множество Σ, отношение R⊆Σ×Σ и конечный набор наблюдаемых предикатов AP. Зададим язык

\[
\varphi ::= \top\mid p\mid\neg\varphi\mid(\varphi\land\varphi)\mid EX\varphi,
\qquad p\in AP,
\]

где EX означает существование R-преемника, удовлетворяющего формуле. Это самостоятельная операциональная спецификация. В ней нет номеров уровней, нулей ФТС, обязательной череды ролей или κ.

Положим

\[
s\equiv_{\mathcal L}t
\iff \forall\varphi\in\mathcal L:\;s\models\varphi\Leftrightarrow t\models\varphi.
\]

Определим Q=Σ/≡_L, q(s)=[s], метки классов и отношение [s]R′[t], если соответствующий конкретный переход существует. Кандидат M′=(Q,R′,AP′).

Это собственная специализация стандартного направления R1/R6 к конечному носителю, не новая общая теорема. Нужные свойства можно доказать непосредственно, не ссылаясь на ФТС.

### 4.2. Почему фактор сохраняет весь язык

Эквивалентность согласует исходные предикаты по определению. Покажем условие ответного перехода. Пусть s≡_L t и sRu. Если ни один преемник v состояния t не эквивалентен u, для каждого такого v существует формула, истинная в u и ложная в v; направление достигается отрицанием. Конечная конъюнкция этих формул истинна в u и ложна у всех преемников t. Тогда EX этой конъюнкции различает s и t — противоречие. Если преемников нет, достаточно EX⊤. Обратное направление симметрично.

Структурная индукция по формулам теперь даёт

\[
\forall s\in\Sigma\;\forall\varphi\in\mathcal L:\quad
s\models\varphi\iff q(s)\models\varphi.
\]

Конечность существенна для использованной конъюнкции. Переход к произвольной бесконечной системе без контроля ветвления и языка не является следствием этого доказательства.

### 4.3. Точная минимальность и её предел

Пусть f:Σ→Z — другое детерминированное представление, и ответ на любую формулу вычисляется только из f(s), без дополнительной памяти о конкретном s. Если f(s)=f(t), все ответы совпадают, следовательно s≡_L t. Значит, существует сюръекция h:f(Σ)→Q с q=h∘f. Отсюда

\[
|Q|\le |f(\Sigma)|.
\]

Это доказывает минимум числа состояний и единственность самого отношения наблюдательной эквивалентности. Оно не доказывает единственность порядка уточнения, универсальное число ступеней или минимум длины программы. Представление с внешней памятью должно включить эту память в Z; иначе сравниваются разные ресурсы.

Если реализация ФТС удовлетворяет тем же посылкам, можно подставить f=f_FTS. Если ФТС обязана отвечать на дополнительные вопросы, их сначала добавляют в L и пересчитывают Q. Если её семантика не задаёт такого f, теорема к ней пока неприменима.

### 4.4. Абстрактная область и композиция

На множествах свойств определим

\[
\alpha(X)=\{B\in Q:B\cap X\ne\varnothing\},\qquad
\gamma(\mathcal B)=\bigcup_{B\in\mathcal B}B.
\]

Тогда α(X)⊆B ⇔ X⊆γ(B), α∘γ=id на P(Q), а γ∘α — замыкание, насыщающее множество целыми классами. Замкнутые множества — все объединения блоков Q. Стабильность разбиения обеспечивает замкнутость этих множеств относительно выбранного predecessor-оператора.

Для вложенных разбиений факторные проекции составляются обычным образом. Это даёт проверяемое согласование отображений. Но тождество на P(Q) не является автоматически тождеством канонического A7 на иных объектах, а композиция работает для любого числа шагов и не выделяет O8 сама по себе.

### 4.5. Почему это самостоятельная альтернатива, а не упаковка ФТС

Алгоритм начинает с различий AP и расщепляет блоки по наблюдаемым переходам. Основание расщепления — формула, которую иначе нельзя правильно вычислить. Имена классов произвольны; очередность разделителей может меняться; готовый результат не зависит от присвоения ему номеров ФТС. Все посылки перечислены в §4.1.

При этом M′ получает носитель и наблюдения как вход. Она не выводит возникновение носителя из несегментированности. Это реальная граница её scope, которая запрещает объявлять результат полным победителем F3, но не превращает используемые множества в скрытую ФТС.

Второй кандидат — correctness kernel: сначала выбирают наблюдаемые операторы, затем удаляют элементы абстрактной области, не меняя их приближённого поведения. Он полезен для проверки избыточности конкретной реализации. Сохранение одного лишь набора операторов нельзя выдавать за сохранение всех исходных меток или всех требований ФТС. ## 5. Точные конечные свидетели и результаты исполнения

Все W1–W6 ниже вычислены собственным кодом на стандартной библиотеке Python; полная программа включена в приложение. Числа не взяты из внешней эмпирической выборки.

### W1. Минимальный фактор и все наблюдаемые формулы

Σ={0,1,2,3,4,5}; переходы 0→2, 1→3, 2→4, 3→3, 4→4, 5→5; единственный исходный предикат p={4,5}.

| Шаг | Разбиение | Что добавилось |
|---|---|---|
| 0 | {0,1,2,3} / {4,5} | Наблюдение p |
| 1 | {0,1,3} / {2} / {4,5} | Различение по непосредственному достижению p |
| 2 | {0} / {1,3} / {2} / {4,5} | Различение по достижению класса {2} |

Перебор всех разбиений даёт 203 кандидата, четыре стабильных с сохранением p и единственный минимум из четырёх блоков. Независимое насыщение денотаций по дополнению, пересечению и EX даёт 16 множеств — все объединения четырёх блоков. Поэтому проверено не только несколько выбранных запросов или глубина 2, а весь язык на этой системе.

**Relation:** alternative. **Verdict:** independent_alternative. **Контрсвидетельство к расширению:** добавить наблюдение, различающее 4 и 5, — прежнее слияние перестанет быть допустимым. **Альтернативное объяснение минимума:** конечная логическая неразличимость в заданном языке. **Мост к ФТС:** только после реализации именно этого контракта обеими моделями.

### W2. Один конец, разные пути

На четырёх состояниях 00,01,10,11 два независимых запроса читают первый или второй бит. Из тривиального разбиения можно сначала выделить первый бит, затем второй; можно наоборот. Промежуточные разбиения {00,01}/{10,11} и {00,10}/{01,11} несравнимы. Конечное разбиение на четыре одиночных класса одинаково.

**Relation:** refuting для импликации «единственный минимальный результат ⇒ единственный порядок уточнения». **Verdict:** contradicts_same_domain для этой импликации в конечных разбиениях. **Предел:** это не готовая допустимая вставка внутрь Dense_FTS с тем же словарём и ценой. **Альтернативное объяснение пути ФТС:** специальный порядок её локальных операций, который нужно доказать отдельно.

### W3. Факторизация не гарантирует восстановительное вложение динамики

Два одинаково помеченных состояния образуют цикл 0→1→0. Их бисимуляционный фактор — одно состояние с петлёй. Для отображения множеств q имеется сечение, выбирающее 0 или 1. Но ни один выбор не сохраняет переход: петля фактора потребовала бы 0→0 либо 1→1, которых нет.

**Relation:** refuting. **Verdict:** contradicts_same_domain для «любой бисимуляционный фактор имеет переходосохраняющее сечение». **Мост:** возможен к A7 только если ι и π должны быть морфизмами именно таких систем. **Контрсвидетельство к глобальному выводу:** α∘γ=id на решётках свойств из §4.4 остаётся верным; нарушено другое типизированное требование. **Остаток:** уточнить типы канонического A7.

### W4. Достаточность без сохранения полной истории

Пусть X₁,X₂ независимы Bernoulli(θ), θ∈{1/4,3/4}. Канал E для упорядоченных выходов 00,01,10,11:

\[
E=\frac1{16}\begin{pmatrix}9&3&3&1\\1&3&3&9\end{pmatrix}.
\]

Статистика T=X₁+X₂ даёт канал

\[
T(E)=\frac1{16}\begin{pmatrix}9&6&1\\1&6&9\end{pmatrix},\qquad
K=\begin{pmatrix}1&0&0&0\\0&1/2&1/2&0\\0&0&0&1\end{pmatrix}.
\]

Непосредственно проверено E=T(E)K; обратное огрубление детерминировано. Следовательно, в конечном статистическом контракте это эквивалентные эксперименты. Риск ошибки различения двух θ при равных prior равен 1/4 и для E, и для T. Статистика чётности имеет одинаковые строки для двух θ и даёт риск 1/2.

Однако T(01)=T(10), хотя вопрос «первый отсчёт равен 1?» различает эти истории. Восстановительный K воспроизводит условное распределение, а не исходный реализованный порядок.

**Relation:** direct для достаточности, limiting для переноса на всё поведение. **Verdict:** supports_local_instance / limits соответственно. **Сильнейшее контрсвидетельство:** запрос к порядку. **Альтернативное объяснение экономии:** обменность семейства относительно θ. Счётчик не объявляется У6 или κ.

### W5. Промежуточные эксперименты и отсутствие универсальной смежности

Для двоичного симметричного канала BSC(ε), 0≤ε<1/2, последовательное зашумление с r даёт ε′=ε+r−2εr. Между ε=0.1 и 0.3 есть ε=0.2: r₁=1/8 и r₂=1/6. Точные рациональные матричные равенства проверены кодом. При равном prior ошибка равна ε, поэтому отношения здесь строгие.

Аналогично выбирается любая промежуточная ε. Это показывает наличие промежуточных статистических представлений даже в бинарной области, где решётка существует.

**Relation:** refuting для отождествления произвольной информационной цепи с дискретной последовательностью обязательных соседей. **Verdict:** contradicts_same_domain для указанного отождествления. **Предел:** параметр шума не доказан новой минимальной формой внутри Σ_FTS. **Альтернатива:** различие между функциональной информативностью и типом локальной формы.

### W6. Полная классификация может быть дорогой

Для контекста G=M={1,…,n}, gIm ⇔ g≠m, каждое B⊆M замкнуто: B′=G\B, B″=B. Поэтому понятий ровно 2ⁿ. Вычисление при n=1,…,6 даёт 2,4,8,16,32,64.

**Relation:** limiting. **Verdict:** limits для предложения «заменить структуру полной FCA-решёткой без дополнительной описательной цены». **Контрсвидетельство к чрезмерному ограничению:** формула g≠m коротка; экспоненциальна явная выдача всех понятий, не обязательно код исходного контекста. **Альтернативное объяснение экономии:** ленивое вычисление нужных запросов вместо материализации всей решётки.

## 7. Какой эксперимент различит M′ и ФТС

### 7.1. Невозможность различения внутри полного контракта эквивалентности

Если равенство ответов доказано для каждого теста t∈L, никакой тест из того же L не различит модели. Иначе он является прямым контрпримером самому равенству. Для случайных моделей аналогичное утверждение требует равенства совместных распределений наблюдаемых транскриптов, если разрешены адаптивные многошаговые тесты; одних отдельных маргинальных рисков может быть недостаточно.

Поэтому корректны три разных эксперимента: поиск нарушения заявленной эквивалентности; сравнение ресурсов при одинаковых ответах; проверка нового заранее объявленного наблюдения, на которое модели дают различные предсказания. Третий вариант расширяет scope и требует дать обеим моделям одинаковые возможности расширения.

### 7.2. Готовая спецификация сравнительного прогона

| Тест | Вход и заранее заданный критерий | Что будет различать модели | Что уже сделано / чего нет |
|---|---|---|---|
| E1: полное конечное сохранение | Система W1; все денотации, полученные насыщением AP по ¬, ∧, EX. | Любой несовпавший ответ означает провал сохранения. | M′ проверена точно; реализации ФТС для этой задачи не предоставлено. |
| E2: цена при одинаковых ответах | Один сериализованный вход, одинаковый язык исполнения и ресурсные лимиты; отдельно подготовка, построение и ответы. | Размер модели, пиковая память, число операций, время, затраты на сертификат. | Задан протокол; сравнительных измерений нет. Нужны реализации и заранее принятая C′. |
| E3: порядок обязательных различений | Четыре состояния W2; запроса два; разрешены обе очередности, итоговые ответы одинаковы. | Если ФТС предсказывает дополнительную обязательную операцию или невозможность одной очередности, проверяется именно это предсказание и её цена. | Обе цепи M′ вычислены; противоречащее операциональное предсказание ФТС ещё должно быть предъявлено. |
| E4: достаточность и история | W4; сначала решения о θ, затем отдельно объявленный запрос к первому отсчёту. | Счётчик эквивалентен полному наблюдению в первом контракте, не во втором. | Обе части точно проверены. Это демонстрация различия контрактов, не измерение ФТС. |
| E5: тип отсутствия и provenance | Пары записей с одинаковыми числовыми значениями, но разными метками: неизвестно; структурно отсутствует; отказ; разные происхождения. | Различия в ответе/закрытии/отказе, если они обязательны по спецификации ФТС. | Протокол готов. Нужно зафиксировать истинные ожидаемые ответы; их нельзя выдумать из обычного смысла слов. |
| E6: перенос между средами | Две конечные системы с одинаковыми текущими наблюдениями, но разными разрешёнными интервенциями или будущими переходами. | Модель, забывшая различие, ошибётся на новом обязательном запросе. | Общая конструкция теста задана; требуется конкретная семантика вмешательства в ФТС. |

Для E2 нельзя выдать случайную разницу времени за структурное преимущество. Нужны одинаковые реализации базовых операций, повторные прогоны, заранее выбранные размеры задач и раздельный отчёт об обучении/построении и исполнении. Эти измерения имеют смысл после E1, а не вместо него.

E5 особенно важен для предложений «статистика + confidence заменяет κ». Если κ наблюдаемо зависит от окна, происхождения или отказа при одинаковом прогнозе, чисто предсказательная модель недостаточна. Если такого различимого поведения не задано, превосходство κ над достаточной статистикой не установлено. Добавление этих наблюдений в M′ допустимо, но оплачивается и может уничтожить первоначальную экономию.

## 8. Предлагаемые записи для EXTERNAL_CONFLICTS

Это готовые записи для рассмотрения, не внесённые изменения в исходный канон. Во всех случаях сторона ФТС указана вместе с её статусом: канонический локальный предикат не подменяется более сильной внешней формулировкой.

### EC-DR09-01 · Минимальный результат и обязательный путь

- **Сторона A:** O7, O8, O9 и производный перенос: «наиболее абстрактное сохраняющее представление подтверждает единственный необходимый порядок ФТС».
- **Сторона B / точный источник:** R1, Thm 5.8 и 6.7, дают результат сохранения/уточнения; W2 показывает две несравнимые промежуточные стадии с одним концом.
- **Область / регистр:** конечные разбиения и операциональная логика; перенос в M-регистр не дан.
- **Мост:** уровни должны быть интерпретированы именно как обязательная последовательность уточнений в той же области. Одного порядка точности недостаточно.
- **Свидетель:** W2, два независимых бита.
- **Решение:** отвергнуть указанное усиление; сохранить локальную Dense_FTS с её явными Σ_FTS,C,T.
- **Незакрытый остаток:** допустимость обеих очередностей внутри словаря ФТС и их полная цена.

### EC-DR09-02 · Минимум различий и минимум стоимости

- **Сторона A:** O9, Приложение E / лист 20; потенциальный вывод «семантический минимум означает C(M′)≤C(FTS)».
- **Сторона B / точный источник:** R1 относится к порядку абстракций; R2, Thm 4.4, имеет отдельные алгоритмические предпосылки; W6 отделяет короткое правило от большого явного вывода.
- **Область / регистр:** представление и вычислительная цена против семантической точности.
- **Мост:** нужна доказанная монотонность выбранной C относительно точности либо конкретное измерение двух реализаций. Такой мост отсутствует.
- **Свидетель:** полнота классификации в W6 и раздельные ресурсы §3.2; это свидетель разрыва понятий, не измеренный проигрыш ФТС.
- **Решение:** `nonconfirmation` полного стоимостного вывода; допустим локальный минимум состояний из §4.3.
- **Незакрытый остаток:** C′, единица распаковки, порядок векторов и реализации.

### EC-DR09-03 · «Информация всегда образует решётку»

- **Сторона A:** возможный мост information lattice → Blackwell order → универсальная схема связности; это производное усиление, не дословный канон.
- **Сторона B / точный источник:** Bertschinger–Rauh, Prop. 16 и Thm 19, различают бинарную и общую области.
- **Область / регистр:** стохастические эксперименты с фиксированным входом, фактор по Blackwell-equivalence.
- **Мост:** детерминированное ядро функции нельзя без доказательства заменить стохастическим сравнением решений.
- **Свидетель:** пара каналов в доказательстве Thm 19; нарушение существования нужной решёточной границы.
- **Решение:** `contradicts_same_domain` для общего тезиса о Blackwell order; ограничить мост, не переносить отрицание на локальную Dense_FTS.
- **Незакрытый остаток:** какой именно информационный порядок нужен сравниваемому операциональному фрагменту.

### EC-DR09-04 · Ретракция свойств и сечение динамики

- **Сторона A:** A7, π∘ι=id; потенциальная идентификация этой пары с любым бисимуляционным фактором.
- **Сторона B / точный источник:** R6 задаёт наблюдательную эквивалентность; собственный W3 исключает переходосохраняющее сечение.
- **Область / регистр:** карты состояний и морфизмы переходов против карт решёток свойств.
- **Мост:** необходимо совпадение типов ι,π и требования сохранения операций.
- **Свидетель:** цикл длины 2 и одноточечный фактор с петлёй.
- **Решение:** отвергнуть неограниченную идентификацию; Galois insertion на множествах свойств не опровергнута.
- **Незакрытый остаток:** фактическая типизация A7 в выбранной реализации ФТС.

### EC-DR09-05 · Независимость и обвинение в скрытой ФТС

- **Сторона A:** O_09 прямо предназначено исключить ситуацию, когда любая альтернатива объявляется скрытой ФТС; Primitive-Unpack требует оплаты примитивов.
- **Сторона B / точный источник:** самостоятельная спецификация §4.1 и полный код приложения используют обычные конечные объекты без канонического порядка. R1–R3 предоставляют внешнюю мотивацию такого способа построения.
- **Область / регистр:** методология аудита и зависимость вывода, не теорема о возникновении семантики.
- **Мост:** «использует равенство/выбор» должно отличаться от «использует теорему о неизбежности всей ФТС».
- **Свидетель:** W1 строится и проверяется при полном удалении терминологии ФТС из программы.
- **Решение:** признать независимость вывода в заданном scope; не объявлять этим полное функциональное покрытие. Противоречие возникнет только при отклонении M′ по одному наличию общих операций.
- **Незакрытый остаток:** универсальный и симметричный критерий раскрытия библиотечных/математических примитивов.

### EC-DR09-06 · Сохранение решения, прогноза и всей истории

- **Сторона A:** производный тезис «достаточная статистика или confidence уже покрывает все функции вплоть до κ».
- **Сторона B / точный источник:** R4 сравнивает решения о параметре; R8 сохраняет распределения будущего в своей области; W4 различает решение о θ и конкретный порядок отсчётов.
- **Область / регистр:** статистическое решение, прогноз и частное чтение У7 — разные контракты.
- **Мост:** требуется доказать, что каждый обязательный ответ ФТС измерим относительно предложенной статистики и что динамика/отказ также сохранены.
- **Свидетель:** истории 01 и 10, один счётчик и разные ответы о первом отсчёте.
- **Решение:** `limits`; статистическая замена допустима только для оговорённых ответов. Ни необходимость κ, ни его заменимость одним confidence не доказаны.
- **Незакрытый остаток:** закрытый тест E5 с канонически обоснованными ответами.

## 12. Воспроизводимость конечных проверок

Программа ниже не импортирует материалы ФТС и не использует внешние пакеты. Она полностью перебирает конечные объекты только заявленных примеров. Все `assert` выполнены успешно. Это вычислительная проверка конечных свидетелей; она не заменяет общего доказательства §4 и не является Lean-сертификацией ФТС.

```python
"""DR-09 finite witnesses; Python standard library only, no FTS axioms."""
from fractions import Fraction as F
from itertools import product
import json

def canonical(blocks):
    return tuple(sorted(tuple(sorted(b)) for b in blocks if b))

def partitions(items):
    if not items:
        yield ()
        return
    first, *rest = items
    for p in partitions(rest):
        yield canonical(((first,),) + p)
        for i in range(len(p)):
            yield canonical(p[:i] + (p[i] + (first,),) + p[i+1:])

def refine(p, test):
    test = set(test)
    return canonical([part for b in p for part in (set(b) & test, set(b) - test)])

def pre(test, edges):
    return {s for s,t in edges if t in test}

states = tuple(range(6))
edges = {(0,2),(1,3),(2,4),(3,3),(4,4),(5,5)}
atom = {4,5}
p = refine((states,), atom)
chain = [p]
while True:
    for block in p:
        candidate = refine(p, pre(block, edges))
        if candidate != p:
            p = candidate
            chain.append(p)
            break
    else:
        break

all_p = sorted(set(partitions(list(states))))
valid = [q for q in all_p if refine(q,atom)==q
         and all(refine(q,pre(b,edges))==q for b in q)]
minimum = min(map(len,valid))
minimizers = [q for q in valid if len(q)==minimum]
assert len(all_p)==203 and minimum==4 and minimizers==[p]
assert p==((0,),(1,3),(2,),(4,5))

# Saturate the denotations under conjunction, negation and EX.
universe = frozenset(states)
den = {universe, frozenset(atom)}
while True:
    old=set(den)
    den |= {universe-d for d in old}
    den |= {frozenset(pre(d,edges)) for d in old}
    den |= {a & b for a in old for b in old}
    if den==old:
        break
assert len(den)==16
assert all(all(set(b)<=d or not(set(b)&d) for b in p) for d in den)

# Incomparable query refinements and the same endpoint.
u=((0,1,2,3),)
left, right={2,3},{1,3}
pl,pr=refine(u,left),refine(u,right)
joint=refine(pl,right)
assert pl!=pr and joint==refine(pr,left)==((0,),(1,),(2,),(3,))
assert refine(pl,right)!=pl and refine(pr,left)!=pr

# A bisimulation quotient need not admit a transition-preserving section.
cycle={(0,1),(1,0)}
sections=[s for s in (0,1) if (s,s) in cycle]
assert sections==[]

# Counts are sufficient for two Bernoulli observations; parity is not.
samples=list(product((0,1),repeat=2))
theta=(F(1,4),F(3,4))
experiment=[[t**sum(x)*(1-t)**(2-sum(x)) for x in samples] for t in theta]
counts=[[sum(row[j] for j,x in enumerate(samples) if sum(x)==k)
         for k in range(3)] for row in experiment]
reconstruct=[[F(1),F(0),F(0),F(0)],
             [F(0),F(1,2),F(1,2),F(0)],
             [F(0),F(0),F(0),F(1)]]
assert [[sum(counts[i][k]*reconstruct[k][j] for k in range(3))
         for j in range(4)] for i in range(2)]==experiment
parity=[[row[0]+row[3],row[1]+row[2]] for row in experiment]
def bayes_error(channel):
    return sum(min(channel[0][j],channel[1][j]) for j in range(len(channel[0])))/2
assert bayes_error(experiment)==bayes_error(counts)==F(1,4)
assert bayes_error(parity)==F(1,2)

# An intermediate binary symmetric channel exists.
def bsc(e):
    return [[1-e,e],[e,1-e]]
def matmul(a,b):
    return [[sum(a[i][k]*b[k][j] for k in range(len(b)))
             for j in range(len(b[0]))] for i in range(len(a))]
p0,mid,p1=F(1,10),F(1,5),F(3,10)
garble1=(mid-p0)/(1-2*p0)
garble2=(p1-mid)/(1-2*mid)
assert matmul(bsc(p0),bsc(garble1))==bsc(mid)
assert matmul(bsc(mid),bsc(garble2))==bsc(p1)

# Exact full FCA size on the contranominal context g I m iff g != m.
def intents(n):
    g=set(range(n))
    closed=[]
    for mask in range(1<<n):
        b={i for i in g if mask>>i&1}
        a={x for x in g if all(x!=m for m in b)}
        b2={m for m in g if all(x!=m for x in a)}
        if b==b2:
            closed.append(b)
    return len(closed)
assert [intents(n) for n in range(1,7)]==[2,4,8,16,32,64]

result={
  'all_partitions':len(all_p), 'stable_label_preserving_partitions':len(valid),
  'minimal_states':minimum,'unique_minimum':len(minimizers)==1,
  'partition_chain':chain,'definable_sets':len(den),
  'query_diamond':{'first_left':pl,'first_right':pr,'endpoint':joint},
  'transition_preserving_sections':len(sections),
  'bayes_error':{'raw':str(bayes_error(experiment)),
    'count':str(bayes_error(counts)),'parity':str(bayes_error(parity))},
  'bsc_garblings':[str(garble1),str(garble2)],
  'contranominal_concepts_n1_to_n6':[intents(n) for n in range(1,7)]
}
print(json.dumps(result,ensure_ascii=False,indent=2))
```
