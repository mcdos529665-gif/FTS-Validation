# DR-07 · [O_07] Локальная невставляемость ФТС

**Исследуемый claim:** `Dense_FTS(−1..7 | Σ_FTS,C,T)`.

**Дата поиска и проверки:** 10 сентября 2026 года, UTC. **Формат:** исследовательский отчёт с проверкой первоисточников, явными математическими свидетелями и проектом записей `EXTERNAL_CONFLICTS`.

ФТС здесь — локальный объект из переданных файлов. Его «информация», «вероятность», «тождество», «реверси», «плотность» и уровни не отождествляются с одноимёнными внешними понятиями. Канонические статусы описываются как статусы проекта, а не как внешние научные вердикты. Математические конструкции, выведенные в этом отчёте, явно отделены от результатов публикаций.

## Найдено

**Локальный внешний инстанс O_07 существует как точная математическая схема. Перенос этой схемы на всю цепь ФТС −1…7 пока не доказан.** Наиболее прозрачный положительный случай: фиксировано конечное множество состояний; представления — все его разбиения; порядок — уточнение; переход расщепляет ровно один блок ровно на два непустых блока. Тогда промежуточное разбиение невозможно. Более общий сертификат получается в системе замкнутых множеств: каждый новый элемент верхнего представления вместе с нижним должен порождать всё верхнее представление. Определение cover и правила для произведений проверены в официальной библиотеке [mathlib, `Order/Cover`](https://leanprover-community.github.io/mathlib4_docs/Mathlib/Order/Cover.html); доказательства конкретных инстансов даны ниже.

**Ranzato–Tapparo не доказывают, что исходная абстракция и её наименьшее полное уточнение образуют cover relation.** Их результат — существование forward complete shell и его связь с наиболее абстрактным strongly preserving domain для фиксированного языка. Ключевое равенство в Theorem 6.7 требует замкнутости языка относительно бесконечных конъюнкций. Между исходной абстракцией и shell могут лежать строгие, но ещё неполные уточнения. Это видно уже из Example 6.3; ниже приведён также независимый конечный контрпример. [Ranzato–Tapparo, 2007, §6.1–6.2, Lemma 6.2, Example 6.3, Theorem 6.7](https://www.math.unipd.it/~ranzato/papers/jlc07.pdf).

**Сильнейший конкретный кандидат $X$ для F1 — выборочное уточнение контекстного остатка на переходе У2→У3.** В модели с четырьмя состояниями нижнее представление различает два контекста, верхнее дополнительно различает два исхода внутри каждого контекста, а $X$ различает исходы только внутри одного. Строгое промежуточное положение доказано. Полный F1 этим ещё не выполнен: требуется показать, что такое представление допустимо в ФТС, не является ранней формой У3, не использует преждевременно `Select` и проходит P5/P6 и полную стоимость $C$.

Получены все четыре запрошенных класса материала:

| Класс поиска | Сильнейший результат | Значение для DR-07 |
|---|---|---|
| `direct` | Cover в решётке разбиений; cover над тривиальным клоном для инволюции; cover в ограниченном классе инвариантных разбиений | Даёт локальные инстансы при явно указанных объектах и ограничениях |
| `limiting` | Язык и вид полноты в Ranzato–Tapparo; условия существования complete shells; критерий одного расщепления | Ограничивает перенос минимальности на невставляемость |
| `alternative` | Correctness kernels; клоны операций; интерполяция логических формул | Предлагает другие точные функции минимизации или промежуточности |
| `refuting` | Неполные промежуточные абстракции; выборочный остаток; односторонняя Moore-абстракция; NAND; отсутствие fixpoint complete shell | Опровергает перечисленные ниже производные обобщения в их математической области |

Ни один найденный внешний результат не содержит отображения всех восьми переходов ФТС с проверенными стоимостью, P5 и P6. Отсутствие такого результата не используется как аргумент о мировой новизне.

### 2. Нормализация предиката без переименования канона

Пусть $\mathcal R_{\Sigma,C,T}$ — заранее зафиксированный класс допустимых представлений, $\sim$ — их содержательная эквивалентность, а $\preceq$ — порядок «не больше выразительных возможностей». Тогда проверяемая версия локального условия:

$$
A\mathrel{\lessdot_{\mathcal R}}B
\quad\Longleftrightarrow\quad
A\prec B\;\land\;
\forall X\in\mathcal R\,
\bigl(A\preceq X\preceq B\Rightarrow X\sim A\lor X\sim B\bigr).
$$

Для конечного фиксированного носителя $\Omega$ один возможный внешний порядок на наблюдениях $E:\Omega\to V_E$:

$$
E\preceq F\iff \exists h\;(E=h\circ F).
$$

Здесь $h$ — допустимый декодер, а взаимная воспроизводимость даёт эквивалентность. Если ограничения на декодеры не замкнуты относительно композиции, транзитивность надо доказывать отдельно. Удобнее сначала задать порядок воспроизводимости, затем ограничить его носитель допустимостью и стоимостью. Ограничение длины каждого декодера без такого аудита может разрушить сам порядок.

**Терминологическая граница.** Обычная order density означает $\forall A\prec B\;\exists X\;(A\prec X\prec B)$, то есть противоположное отсутствию промежуточных объектов. Каноническое имя `Dense_FTS` сохраняется; его внешний формальный аналог в этой задаче — локальная насыщенность цепи отношениями cover. В mathlib это различие выражено, в частности, теоремой `not_covBy_of_denselyOrdered`. [Официальная документация](https://leanprover-community.github.io/mathlib4_docs/Mathlib/Order/Cover.html).

### 3. Условия корректного переноса

Для положительного переноса достаточно вложения порядков

$$
J:\mathcal R/\!\sim\ \hookrightarrow\mathcal P
$$

и доказательства $J(A)\lessdot_{\mathcal P}J(B)$. Любое строгое локальное промежуточное представление тогда дало бы запрещённый внешний промежуточный объект. Это короткое доказательство относится к общей теории порядков; оно не доказывает существования самого $J$.

Для отрицательного переноса условия иные: внешний $Y$ между $J(A)$ и $J(B)$ должен **подниматься** до допустимого $X\in\mathcal R$. Объект за пределами образа $J$, нарушающий стоимость или использующий будущий аппарат, не опровергает локальный O_07.

Из этого следуют необходимые зависимости:

1. Независимо задать класс представлений и границы ресурсов до проверки конкретного $X$.
2. Зафиксировать, сравниваются ли наблюдения, множества выразимых предикатов, абстрактные домены или клоны операций.
3. Доказать строгость обоих концов и сохранение/отражение порядка мостом.
4. Проверить все допустимые промежуточные объекты, а не только предложенный словарь примитивов.
5. Отдельно проверить семантический паспорт перехода ФТС и стоимость.

Скалярные формы $x,-x,|x|,-|x|,x^2,-x^2$ этого моста не задают. Например, $x\mapsto-x$ обратимо и сохраняет различимость состояний. Это не опровержение `Dist/Δ`: это отказ от неподходящего отождествления наблюдения с арифметической проекцией. Данный риск уже отражён в проектных записях о скалярном мосте, включая EC-002.

## Вывод

### 1. Точный положительный инстанс: разбиения

**Утверждение R1 — самостоятельное доказательство по стандартному определению разбиения.** Пусть $\Omega$ конечно, а $P\preceq Q$ означает, что $Q$ уточняет $P$. В классе всех разбиений $\Omega$:

$$
P\lessdot Q
\iff
\text{ровно один блок }P\text{ разделён на два непустых блока, остальные сохранены}
\iff |Q|=|P|+1.
$$

Если разделён один блок на два, любое промежуточное разбиение либо соединяет эти два блока, либо разделяет их. Если изменены два блока, можно выполнить только одно из расщеплений. Если один блок разделён на три и более частей, можно объединить две из этих частей. В обоих последних случаях возникает строгий промежуточный объект.

Формальный носитель сверялся с [mathlib, `Finpartition`](https://leanprover-community.github.io/mathlib4_docs/Mathlib/Order/Partition/Finpartition.html), а действие перестановок на решётке разбиений — с [Hanlon, 1981, §1, с. 319–320](https://msp.org/pjm/1981/96-2/pjm-v96-n2-p04-p.pdf). Бинарный критерий выше не приписывается Hanlon как отдельная пронумерованная теорема: здесь дано его полное доказательство.

Более информативная форма: для каждого блока $B\in P$ обозначим через $k_B$ число блоков $Q$, содержащихся в $B$. Интервал $[P,Q]$ изоморфен произведению решёток разбиений этих $k_B$ частей. Следовательно,

$$
|[P,Q]|=\prod_{B\in P}\operatorname{Bell}(k_B).
$$

Если новая бинарная проверка независимо расщепляет $k$ старых блоков, интервал — булева решётка на $k$ координатах и содержит $2^k-2$ строгих промежуточных представлений. **Один новый бинарный вопрос не гарантирует одного cover:** он может разделять много контекстов одновременно. Общее правило о cover в произведении проверено в `Prod.mk_covBy_mk_iff`: меняется ровно одна координата и именно на cover. [mathlib](https://leanprover-community.github.io/mathlib4_docs/Mathlib/Order/Cover.html).

Для ФТС это даёт условный сертификат: конкретный переход получает `supports_local_instance`, если его образы удовлетворяют R1 и доказан мост. Ни количество названий уровней, ни минимальное число операций не заменяют этот сертификат. Даже все cover вдоль цепи не доказывают единственности самой цепи; это отдельный вопрос, уже отмеченный в проектном NC-01.

### 2. Более общий сертификат: порождение замыканием

**Утверждение R2 — самостоятельное доказательство.** Пусть $\operatorname{cl}:\mathcal P(U)\to\mathcal P(U)$ — экстенсивный, монотонный, идемпотентный оператор; $A\subsetneq B$ — замкнутые множества. Тогда в решётке его замкнутых множеств:

$$
A\lessdot B
\iff
\forall b\in B\setminus A\quad \operatorname{cl}(A\cup\{b\})=B.
$$

Доказательство: каждое указанное замыкание лежит между $A$ и $B$ и строго больше $A$. При cover оно равно $B$. Обратно, любое строгое промежуточное замкнутое $X$ содержит некоторый $b\notin A$; тогда $B=\operatorname{cl}(A\cup\{b\})\subseteq X$, противоречие.

Это пригодный для ФТС тип свидетельства атомарности: **любой доступный новый смысловой элемент вынуждает весь верхний объект**. Но надо задать само замыкание: композицию, конъюнкцию, отрицание, семантическую эквивалентность, допустимые контексты и т. п. Если стоимость отсекает часть замкнутых объектов, интервал проверяется в полученном подклассе отдельно. Минимальный размер набора образующих существенно слабее R2.

### 3. Что именно даёт Ranzato–Tapparo

Пусть $D\subseteq C$ — семейство конкретизаций абстрактного домена, замкнутое относительно произвольных встреч, включая пустую. Для набора операций $F$ forward completeness означает, что результаты применения каждой операции к представимым аргументам снова представимы:

$$
\forall f\in F\;\forall \vec d\in D^{\operatorname{arity}(f)}\quad f(\vec d)\in D.
$$

Соответствующее уточнение можно записать в ориентации «больше представимой информации — выше»:

$$
S_F(A)=\bigcap\{D\supseteq A:\ D\text{ Moore-замкнуто и }F\text{-замкнуто}\}.
$$

Это **наименьший элемент среди полных уточнений**. Квантор не пробегает все неполные промежуточные домены. В uco-порядке статьи ориентация точности обратна включению семейств; поэтому авторская конструкция выражается через greatest fixpoint. Смешение этих ориентаций может ошибочно превратить least/greatest в утверждение о соседстве. [S03, Lemma 6.2 и Theorem 6.7](https://www.math.unipd.it/~ranzato/papers/jlc07.pdf).

Простой независимый свидетель различия:

$$
C=\{0<1<2<3\},\quad A=\{0,3\},\quad
f(0)=1,\ f(1)=2,\ f(2)=2,\ f(3)=3.
$$

Все указанные семейства содержат верх и замкнуты по встречам. Функция монотонна. Полнота вынуждает сначала $1$, затем $2$, поэтому

$$
S_f(A)=C,\qquad A\subsetneq X=\{0,1,3\}\subsetneq S_f(A).
$$

$X$ допустим как абстрактный домен, но неполон, поскольку $f(1)=2\notin X$. Значит, **существование единственного наименьшего полного уточнения не влечёт cover даже на конечной цепи и для одной монотонной операции**.

Можно получить cover искусственным изменением области:

$$
\mathcal R'=\{A\}\cup\{D\supseteq A:D\text{ является }F\text{-полным доменом}\}.
$$

Если $A\ne S_F(A)$, в этом классе $A\lessdot S_F(A)$. Но требование «кроме исходного объекта, все кандидаты должны быть полными» должно иметь независимое основание. В классе, состоящем **только** из полных доменов, неполный $A$ вообще не является элементом: фраза «его cover» там некорректна.

Алгоритмический follow-up тоже не устраняет это различие. В Theorem 4.4 работа ведётся с Galois insertion абстракции $\mathcal A$ пространства доменов. Предполагается DCC: всякая убывающая цепь стабилизируется. Дополнительно требуется одно из двух условий: $\mathcal A$ backward complete для $F^M$, либо $\mathcal A$ forward complete для оператора $S_F$. Здесь $F^M(D)=M(F(\gamma(D)))$, а $M$ — Moore-замыкание. Тогда для каждого входа $a$ алгоритм завершается и возвращает $\alpha(S_F(\gamma(a)))$. Cover входа и выхода из этого не следует. [Ranzato–Tapparo, 2008, §4, Theorem 4.4, авторские с. 23–24](https://www.math.unipd.it/~ranzato/papers/ic08.pdf).

### 4. Проверка примера с квадратом и обнаруженная неточность версии

В авторской версии S03, Example 6.3, с. 21, начальный домен:

$$
A_0=\{\varnothing,\mathbb Z_{\le0},\{0\},\mathbb Z_{\ge0},\mathbb Z\},
\qquad sq(S)=\{x^2:x\in S\}.
$$

Первые уточнения добавляют множества степеней $Q_n=\{z^{2^n}:z\in\mathbb Z\}\$. Уже $A_1=A_0\cup\{Q_1\}$ — строгая промежуточная абстракция до полного замыкания. [Оригинал, Example 6.3](https://www.math.unipd.it/~ranzato/papers/jlc07.pdf).

**Независимая проверка полного семейства.** Для всех $n\ge1$, $Q_{n+1}\subsetneq Q_n$, а

$$
\bigcap_{n\ge1}Q_n=\{0,1\}.
$$

Действительно, у положительного целого $m>1$ хотя бы один ненулевой показатель в разложении на простые множители; он не может делиться на все $2^n$. Отрицательные числа уже не входят в $Q_1$. Поэтому правильное Moore- и square-замкнутое семейство:

$$
S_{sq}(A_0)=A_0\cup\{Q_n:n\ge1\}\cup\{\{0,1\}\}.
$$

Его замкнутость проверяется непосредственно; минимальность следует из вынужденного включения всех $Q_n$ и их пересечения. Конечные $A_n=A_0\cup\{Q_1,\ldots,Q_n\}$ остаются собственными промежуточными Moore-семействами.

В проверенном авторском PDF итоговая строка Example 6.3 не выписывает добавку $\{0,1\}$. Это **выявленная здесь неточность записи**, а не найденное официальное erratum. В arXiv v3, кроме того, исходные знаковые множества записаны со строгими знаками; в авторском PDF они нестрогие. Финальный издательский PDF получить для построчной сверки не удалось, поэтому неточность не приписывается без оговорки печатной журнальной версии. Основной отрицательный вывод не зависит ни от предельной строки, ни от исправления: достаточно первых двух уточнений или конечного свидетеля из предыдущего подраздела.

### 5. Где смена формализма создаёт промежуточный объект

**Разбиения против всех абстрактных доменов.** На $\Omega=\{a,b\}$ coarse и discrete разбиения соседние. Их булевы семейства событий:

$$
D_0=\{\varnothing,\Omega\},\qquad D_2=\mathcal P(\Omega).
$$

Но существует

$$
D_0\subsetneq D_1=\{\varnothing,\{a\},\Omega\}\subsetneq D_2.
$$

$D_1$ замкнуто по произвольным пересечениям и задаёт полноценную Moore-абстракцию. Оно не замкнуто по дополнению и потому не является булевым семейством разбиения. Следовательно, cover в partition lattice не переносится автоматически в lattice of all abstractions. Если язык требует отрицания и полную булеву замкнутость, этот $X$ исключается содержательно. Различие partitioning/nonpartitioning domains проверено также по [Giacobazzi–Ranzato, 2014, §4.1, Example 4.1, авторские с. 12–13](https://www.math.unipd.it/~ranzato/papers/ic14.pdf); конкретный двухточечный свидетель здесь самостоятельный.

**Плотное семейство уточнений.** На полной цепи $[0,1]$ зададим $\rho_t(x)=\max(x,t)$. Для каждого $t$ это монотонный, экстенсивный, идемпотентный оператор. При $t<s$:

$$
\rho_t<\rho_{(t+s)/2}<\rho_s
$$

в поточечном uco-порядке. Таким образом, вполне корректный класс абстракций может быть плотным и не иметь соседних различных элементов. Это самостоятельный контрпример к универсальной дискретности уточнений; он не утверждает, что всякая решётка абстракций плотна. Перенос на ФТС потребовал бы разрешённых непрерывных параметров и соответствующего моста.

### 6. Когда ограничение симметрией действительно исключает $X$

Возьмём $\Omega=\{a,b,c,d\}$, $P=\{ab,cd\}$, $Q=\{a,b,c,d\}$ и перестановку $g=(a\ c)(b\ d)$. Интервал всех разбиений содержит ровно четыре объекта:

$$
P,\quad X=\{a,b,cd\},\quad X'=\{ab,c,d\},\quad Q.
$$

Имеем $g(P)=P$, $g(Q)=Q$, $g(X)=X'\ne X$. Поэтому в классе $g$-инвариантных разбиений между $P$ и $Q$ нет объекта: **там это cover**. В полном классе — не cover.

Это самостоятельный конечный инстанс формализма fixed-point partition lattices, определённого в [Hanlon, 1981, §1](https://msp.org/pjm/1981/96-2/pjm-v96-n2-p04-p.pdf). В общем случае $k$ независимых бинарных расщеплений и транзитивного действия на их координатах инвариантными подмножествами координат остаются только пустое и полное.

Для ФТС это содержательный путь положительного результата: если независимые требования делают выборочное различение контекстов недопустимым, одновременное расщепление может стать локально атомарным. Но фраза «операция едина» недостаточна. Надо доказать инвариантность **каждого допустимого представления** относительно заданного действия. Запрет, введённый только после обнаружения $X$ ради сохранения O_07, доказательством не является.

### 7. Minimal basis, minimal clone и невставляемость

Клон — семейство операций фиксированного носителя, содержащее проекции и замкнутое относительно подстановки. Minimal clone имеет ровно два подклонa: тривиальный клон проекций и себя. Это буквально cover над тривиальным клоном, а не просто минимальный список образующих. Определение проверено по первичному тексту [Waldhauser, *Minimal clones with weakly abelian representations*, §1, с. 1](https://arxiv.org/abs/1102.2081).

**Самостоятельный положительный инстанс.** Пусть $f\ne id$, $f^2=id$. Без дополнительных констант клон, порождённый $f$, состоит из операций $x_i$ и $f(x_i)$. Любая непроекционная операция диагональной подстановкой порождает $f$, поэтому промежуточного клона нет. Это строгая атомарность одной инволюции в фиксированном операционном регистре.

Мост к словарю Д возможен только для изолированной возможности выполнить инволюцию. Он обрывается, если нижний уровень уже содержит эту возможность, если доступны иные операции/константы, или если вместо операционной выразительности сравнивается различимость состояний: обратимая инволюция не добавляет информации наблюдению.

**Самостоятельный отрицательный инстанс.** Одноэлементный базис $\{NAND\}$ минимален по включению как порождающий набор своего нетривиального клона. Однако

$$
\mathrm{Proj}\subsetneq\mathrm{Cl}(AND)\subsetneq\mathrm{Cl}(NAND),
$$

поскольку

$$
AND(x,y)=NAND(NAND(x,y),NAND(x,y)).
$$

$AND$ не проекция; все термы из $AND$ монотонны, а $NAND$ немонотонна. Поэтому оба включения строгие. Отсюда нельзя выводить семантическую невставляемость из того, что добавлен один синтаксический примитив. Цена реализации $AND$ через $NAND$ — другой вопрос: этот пример не приписывает ей нулевую стоимость в ФТС.

### 8. Интерполяция: что она опровергает, а что не подтверждает

Теорема Lyndon даёт для импликации $S\Rightarrow T$ промежуточную формулу $M$, причём отношения в $M$ удовлетворяют ограничениям общего словаря и полярности. Утверждение и используемые соглашения проверены в §1, с. 129–130; доказательство — §5. [Lyndon, 1959](https://msp.org/pjm/1959/9-1/pjm-v9-n1-p12-p.pdf).

Условия $S\Rightarrow M\Rightarrow T$ **не требуют строгих** импликаций. Интерполянт может быть эквивалентен краю. Кроме того, порядок формул по следованию не равен порядку выразительности языков и не включает бюджет выражения. Поэтому «существует интерполяция ⇒ O_07 опровергнут» — неверный перенос.

Есть отдельный строгий отрицательный результат, который можно доказать непосредственно. Пусть доступны все конечные пропозициональные формулы над фиксированным бесконечным запасом переменных, без ограничения длины. Если $\varphi\Rightarrow\psi$ и не $\psi\Rightarrow\varphi$, возьмём переменную $r$, не встречающуюся в краях, и положим

$$
\theta=\varphi\lor(\psi\land r).
$$

Тогда $\varphi\Rightarrow\theta\Rightarrow\psi$, и обе импликации строгие: на оценке, удовлетворяющей $\psi\land\neg\varphi$, значения $r=1$ и $r=0$ дают два свидетеля. Это доказывает плотность данного порядка. Новая переменная здесь берётся из уже фиксированного бесконечного словаря, но она не принадлежит общему конечному словарю краёв; конструкция не является усилением Lyndon interpolation в том же словарном ограничении. При фиксированном конечном словаре существуют атомы и cover. Для ФТС решающим остаётся разрешение ресурса $r$.

### 9. Независимые критерии оптимальности

Giacobazzi–Ranzato предлагают correctness kernel: наиболее грубую абстракцию, сохраняющую заданные best correct approximations выбранных операций. Theorem 3.2 даёт условие существования через непрерывность соответствующих составных функций. Это позволяет проверять, действительно ли удаление части домена меняет выбранное вычислительное поведение. [S06, Theorem 3.2, авторская с. 9](https://www.math.unipd.it/~ranzato/papers/ic14.pdf).

Для ФТС это `independent_alternative` к части RoleNec: если роль удаляется без изменения заранее выбранного набора наблюдаемых операций, её необходимость в этой области не подтверждена. Но сохранение этих операций не означает сохранения всей семантики ФТС, а coarsest behavior-preserving abstraction не означает cover.

Точный проверяемый предикат здесь можно записать через замыкания на одном конкретном носителе: для всех выбранных унарных $f$ требуется $\rho_B\circ f\circ\rho_B=\rho_A\circ f\circ\rho_A$. Theorem 3.2 предполагает непрерывность $f\circ\rho_A$, где $\rho_A=\gamma_A\circ\alpha_A$; область квантификации и выбранное $F$ фиксированы. Это равенство конкретизированных best correct approximations, а не равенство произвольных абстрактных программ.

Есть и существенная граница самой программы completeness. В Giacobazzi–Ranzato–Scozzari конструктивное существование обычных complete shells/core связано с условиями на семантические функции (Theorems 5.3 и 5.10). Для **fixpoint completeness** даже конечность не гарантирует shell: Example 5.16 содержит явный контрпример. [S04, §5, авторские с. 25, 27, 30](https://doi.org/10.1145/333979.333989).

В унарной записи обычная backward completeness пары входного/выходного замыканий имеет вид $\eta\circ f=\eta\circ f\circ\rho$; абсолютный случай — $\rho\circ f=\rho\circ f\circ\rho$. В конструктивных теоремах S04 функции непрерывны в смысле сохранения направленных супремумов. Для операций нескольких аргументов входное замыкание применяется покомпонентно. Это иной предикат, чем forward completeness $f\circ\rho=\rho\circ f\circ\rho$ и чем приведённое далее равенство на наименьших неподвижных точках.

Точный конечный свидетель из Example 5.16:

$$
C=\{0<1<2<3<4\},\quad g=(0,0,0,4,4),
$$

$$
\operatorname{Fix}(\rho_1)=\{1,3,4\},\quad
\operatorname{Fix}(\rho_2)=\{2,3,4\},\quad
\operatorname{Fix}(\mu)=\{3,4\},\quad \mu=\rho_1\vee\rho_2.
$$

Проверка уравнения fixpoint completeness даёт:

| Замыкание | $\rho(\operatorname{lfp}g)$ | $\operatorname{lfp}(\rho\circ g)$ | Полнота |
|---|---:|---:|---|
| $\rho_1$ | 1 | 1 | Да |
| $\rho_2$ | 2 | 2 | Да |
| $\mu$ | 3 | 4 | Нет |

Если бы существовало наиболее грубое fixpoint-complete уточнение $\mu$, оно было бы грубее обоих $\rho_i$, а значит совпало бы с их join $\mu$, который неполон. Это противоречие. **Данный результат не отрицает существование forward complete shell у Ranzato–Tapparo:** изменён предикат полноты, и именно эту границу нельзя стирать.

## Что не закрыто

### 1. Паспорт сильнейшего кандидата $X$ для F1

**Имя кандидата:** `X_selective_residual`, или $X_{B_*}$. **Предполагаемый переход:** У2→У3; кандидатный мост $E\mapsto(E,r)$, уже обсуждаемый в материалах проекта. **Область доказанного результата:** конечные наблюдения/разбиения на фиксированном носителе, без подстановки обычного равенства вместо ФТС-кодирования.

| Состояние | Старый код $E$ | Полный остаток $r$ | Выборочный остаток $q$ | $X=(E,q)$ |
|---|---:|---:|---:|---|
| $a$ | 0 | 0 | 0 | (0,0) |
| $b$ | 0 | 1 | 1 | (0,1) |
| $c$ | 1 | 0 | 0 | (1,0) |
| $d$ | 1 | 1 | 0 | (1,0) |

Здесь $q=r$ в контексте $E=0$, а в контексте $E=1$ результат фиксирован. Следовательно,

$$
\ker E=\{ab,cd\},\quad
\ker X=\{a,b,cd\},\quad
\ker(E,r)=\{a,b,c,d\}.
$$

Имеются декодеры $E=\pi_1\circ X$ и $X=h\circ(E,r)$. При этом $X$ не факторизуется через $E$: $a,b$ имеют одинаковый $E$, но разные $X$. Верхнее наблюдение не факторизуется через $X$: $c,d$ имеют одинаковый $X$, но разные $(E,r)$. Таким образом,

$$
E\prec X\prec(E,r).
$$

В булевых языках событий соответствующие мощности равны 4, 8 и 16. Это не оценка стоимости ФТС, а дополнительный конечный свидетель строгости.

| Проверка F1 / P5 / P6 | Что получено | Что мешает считать проверку закрытой |
|---|---|---|
| Два строгих включения | Доказаны через пары $a,b$ и $c,d$ | Требуется доказать, что именно эти наблюдения реализуют соседние $M_2,M_3$ |
| RoleNec | Удаление $q$ уничтожает различение $a,b$ | Абляция доказывает роль в модели, но не отдельную роль уровня ФТС |
| QuestionGain | «Различаются ли два исхода внутри контекста $B_*$?» не вычисляется из $E$ | Надо исключить кодовую перекодировку и скрытое использование уже данного `Dist` |
| Наблюдаемый след | Два исхода $q(a)\ne q(b)$ | Реальный носитель, процедура наблюдения и контекст ФТС не заданы |
| Новая граница | В модели снимается одно старое отождествление, другое сохраняется | Такая частичность может оказаться ранней формой У3, а не новой границей уровня |
| Новый тип ошибки | Ложное отождествление $a,b$ устраняется, $c,d$ остаётся | Не доказана несводимость к уже указанной ошибке У2→У3 |
| P5: правая часть | Можно выписать множества исключённых состояний | Не доказано соответствие правой части и нулевой границе в регистре ФТС |
| Нет будущих операторов | Таблица задаётся как фиксированное наблюдение над теми же состояниями | Её реализация может требовать `Select`/поля; декларация таблицы не делает это бесплатным |
| Стоимость | Нового внешнего источника данных в математической модели нет | Требуются $C(E)$, $C(X)$, $C(E,r)$, распаковка $h$, адресации контекста и правило сравнения затрат |
| Не повтор / не ранняя форма / не метастатус | Строгое отличие наблюдений доказано | Семантическая самостоятельность $X$ не доказана |

**Вердикт кандидата:** `insufficient_evidence` для полного F1; `contradicts_same_domain` для утверждения «переход от данного $E$ к данному $(E,r)$ является cover среди всех разбиений данного носителя».

Наиболее сильное возражение против кандидата — независимо обоснованная инвариантность относительно обмена контекстами: тогда $X$ исключён, как показано выше. Альтернативное объяснение — это частичная реализация У3. Оба возражения должны быть доказаны через ранее заданные правила, а не следовать из желания сохранить соседство.

Внешний кандидат из Ranzato–Tapparo, $A_1=A_0\cup\{Q_1\}$, сильнее как опубликованный пример промежуточной абстракции, но слабее как кандидат **для ФТС**: совпадение операции square с арифметическим аналогом агрегации ещё не даёт соответствия `Agg_i`, роли, вопроса или стоимости. Поэтому он не заменяет `X_selective_residual` в F1.

### 3. Конкретный незакрытый остаток

Для решения следующего шага достаточно формализовать **один** интервал У2→У3: реальные $\Omega,E,r$; допустимые декодеры; замыкание операций; правило инвариантности либо разрешение контекстного ограничения; полные затраты; семантическую эквивалентность для проверки «ранняя форма». После этого выборочный остаток либо становится допустимым строгим $X$, либо исключается конкретным нарушением. Для положительного результата можно предъявить R1, R2 или исчерпывающий сертификат конечного интервала. Для отрицательного требуется полный паспорт F1, а не только удачная внешняя диаграмма.

### EC-012 — Наименьшее полное уточнение не обязано быть cover

- **Тип / состояние:** `formal_counterexample`; `resolved_working_correction` для мостового вывода, `open` для O_07.
- **Сторона ФТС:** `O_07`, §6.0–6.1; возможная производная импликация `REFINE-MIN ⇒ DENSE`. Статус этой импликации до аудита — неподтверждённый мост; она не приписывается прежнему DR как установленный результат.
- **Внешняя сторона:** Ranzato–Tapparo, 2007, Lemma 6.2, Theorem 6.7 и Example 6.3; [DOI](https://doi.org/10.1093/logcom/exl035), [проверенная авторская версия](https://www.math.unipd.it/~ranzato/papers/jlc07.pdf).
- **Область / кванторы:** Moore-домены на одной конкретной решётке; наименьший $F$-полный домен среди уточнений исходного. Cover требует квантора по всем допустимым доменам интервала.
- **Мост:** приравнивание `REFINE-MIN` к существованию shell, затем без дополнительного основания расширение квантора на неполные представления.
- **Свидетель:** $C=\{0<1<2<3\}, A=\{0,3\}, f=(1,2,2,3), X=\{0,1,3\}, S_f(A)=C$. Все домены допустимы в одной математической области; $X$ строго промежуточен.
- **Решение:** сохранить результат о наименьшем полном уточнении; удалить вывод о cover без отдельного критерия интервала. Рабочий статус импликации — `contradicted`.
- **Незакрытый остаток:** задают ли $\Sigma_{FTS},C,T$ независимый запрет на неполные $X$, и принадлежит ли нижний объект выбранному классу?

### EC-013 — Минимальный словарь не гарантирует семантический атом

- **Тип / состояние:** `formal_counterexample`; `scoped_open` для аргумента словаря Д.
- **Сторона ФТС:** §6.1, кандидатная атомарность Д и исключение вставки через разложение примитива; статус `candidate_v14`.
- **Внешняя сторона:** точное определение minimal clone, Waldhauser, §1, с. 1; [arXiv:1102.2081v1](https://arxiv.org/abs/1102.2081). NAND-контрпример — самостоятельное доказательство настоящего отчёта, E13.
- **Область / кванторы:** операционные клоны на фиксированном булевом носителе, замкнутые относительно всех подстановок; cover требует исключить все промежуточные клоны, а не все меньшие списки примитивов.
- **Мост:** «оператор нельзя удалить из выбранного базиса» заменяется на «между замкнутыми выразительными возможностями нет объекта».
- **Свидетель:** $\mathrm{Proj}\subsetneq\mathrm{Cl}(AND)\subsetneq\mathrm{Cl}(NAND)$, при одноэлементном базисе верхнего клона.
- **Решение:** не использовать синтаксическую независимость как достаточное доказательство O_07. Для положительного решения потребовать критерий R2 или классификацию интервала над уже доступным нижним клоном.
- **Незакрытый остаток:** полное замыкание словаря Д, константы, операции нижних уровней, допустимые композиции и их стоимость. Возможен положительный результат для инволюции, но он ещё не идентифицирован с переходами ФТС.

### EC-014 — Cover разбиений не сохраняется при переходе ко всем абстракциям

- **Тип / состояние:** `domain_mismatch` с явным контрпримером; `resolved_working_correction` для расширения области.
- **Сторона ФТС:** предполагаемый внешний partition-мост для O_07; более сильный вывод о невставляемости среди всех представлений.
- **Внешняя сторона:** стандартное различие partitioning/nonpartitioning domains, Giacobazzi–Ranzato, 2014, §4.1, Example 4.1; [DOI](https://doi.org/10.1016/j.ic.2014.02.003), [оригинал](https://www.math.unipd.it/~ranzato/papers/ic14.pdf). Двухточечный свидетель E11 — самостоятельный.
- **Область / мост:** булевы семейства разбиений вкладываются в Moore-семейства; вложение порядка не обязано сохранять cover при расширении окружающего класса.
- **Свидетель:** $\{\varnothing,\Omega\}\subsetneq\{\varnothing,\{a\},\Omega\}\subsetneq\mathcal P(\Omega)$, $\Omega=\{a,b\}$.
- **Решение:** указывать `partitioning` как существенную предпосылку; при её снятии заново проверять интервал. Cover в меньшем классе сохраняется как локальный результат.
- **Незакрытый остаток:** требует ли ФТС булевой/комплементарной замкнутости именно семантических представлений? Наличие знака анти-формы не заменяет этого доказательства.

### EC-015 — Выборочный остаток как открытый вызов F1

- **Тип / состояние:** `candidate_counterexample`; `scoped_open`.
- **Сторона ФТС:** `O_07`, `F1`, переход `T_02_03`, P5/P6 и `20_CE_метрика`; локальная невставляемость между кодированием и контекстным различением.

При доказанном нарушении независимого ограничения — исключить данный $X$ с указанием нарушенного правила.
- **Незакрытый остаток:** ранняя форма У3; контекстная инвариантность; преждевременный `Select`; стоимость адресации контекста; новый тип ошибки и правая часть.

### Приложение: воспроизводимый конечный перебор

Код использует только стандартную библиотеку Python 3. Ожидаемый результат: 15 разбиений, 45 строго сравнимых пар, 2 промежуточных разбиения основного интервала, 0 инвариантных промежуточных объектов; все проверки `assert` проходят.

```python
"""Independent finite witnesses for DR-07; no FTS semantics assumed."""
from itertools import combinations
import json

def partitions(xs):
    if not xs:
        yield frozenset()
        return
    x, *tail = xs
    for p in partitions(tail):
        yield p | {frozenset({x})}
        for b in p:
            yield (p - {b}) | {b | {x}}

def le(p, q):  # coarse to fine
    return all(any(b <= a for a in p) for b in q)

def proper_between(p, q, universe):
    return [x for x in universe if x != p and x != q and le(p, x) and le(x, q)]

def moore(d, top):
    return top in d and all(a & b in d for a in d for b in d)

ps = set(partitions(list(range(4))))
P = frozenset({frozenset({0, 1}), frozenset({2, 3})})
Q = frozenset(frozenset({x}) for x in range(4))
mid = proper_between(P, Q, ps)
assert len(ps) == 15 and len(mid) == 2
checked = 0
for p in ps:
    for q in ps:
        if p != q and le(p, q):
            assert (not proper_between(p, q, ps)) == (len(q) == len(p) + 1)
            checked += 1
g = {0: 2, 2: 0, 1: 3, 3: 1}
def permute(p):
    return frozenset(frozenset(g[x] for x in b) for b in p)
assert permute(P) == P and permute(Q) == Q
assert all(permute(x) != x for x in mid)

top = frozenset({0, 1})
empty = frozenset()
d0 = frozenset({empty, top})
d1 = d0 | {frozenset({0})}
d2 = d1 | {frozenset({1})}
assert d0 < d1 < d2 and all(moore(d, top) for d in [d0, d1, d2])

f = {0: 1, 1: 2, 2: 2, 3: 3}
A, X, B = {0, 3}, {0, 1, 3}, {0, 1, 2, 3}
assert A < X < B and any(f[x] not in X for x in X)
complete_extensions = [set(s) for n in range(5) for s in combinations(range(4), n)
                       if A <= set(s) and all(f[x] in s for x in s)]
assert complete_extensions == [B]

def closure(fixed):
    return lambda x: min(y for y in fixed if y >= x)

def lfp(h):
    x = 0
    while h(x) != x:
        x = h(x)
    return x

g5 = {0: 0, 1: 0, 2: 0, 3: 4, 4: 4}
values = []
for fixed in [{1, 3, 4}, {2, 3, 4}, {3, 4}]:
    rho = closure(fixed)
    values.append([rho(lfp(lambda x: g5[x])), lfp(lambda x: rho(g5[x]))])
assert values == [[1, 1], [2, 2], [3, 4]]

nand = lambda x, y: 1 - x*y
assert all(nand(nand(x,y),nand(x,y)) == x*y for x in [0,1] for y in [0,1])

print(json.dumps({"partitions_of_four":len(ps), "comparable_strict_pairs_checked":checked,
 "intermediates_P_Q":len(mid),"invariant_intermediates":0,
```
