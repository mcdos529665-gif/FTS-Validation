# Полнотекстовые работы E5

Здесь хранятся шесть работ, переданных исследователем 27 июля 2026 года.

В каждом каталоге:

- `source.en.md` — неизменённый Markdown после OCR/MinerU;
- `DOSSIER.ru.md` — русское исследовательское досье для чтения и второго
  screening-прохода.

Общий паспорт находится в `../PAPER_INTAKE.tsv`. Контрольная сумма в нём относится
к исходному файлу и должна совпадать с копией `source.en.md`.

## Важные ограничения

- Досье переводит и структурирует смысл, но не является полным построчным
  переводом статьи.
- Формулы в досье либо перенесены из оригинала, либо приведены только как краткая
  запись результата. Для формальной ссылки открывать соответствующее место в
  `source.en.md`.
- Часть OCR-файлов содержит внешние ссылки на изображения MinerU. Текст и LaTeX
  сохранены локально, но для просмотра некоторых диаграмм или рисунков может
  потребоваться сеть.
- Работа Блэквелла содержит редакторскую пометку о нормализации обозначений и
  восстановлении пропущенных шагов; её Markdown не считается дипломатической
  транскрипцией печатной статьи.
- Все шесть работ имеют статус `[внешнее]` и не меняют `St_FTS`.

## Порядок чтения для поиска сопряжений

1. Прочитать русское досье.
2. Проверить указанные теоремы и формулы в `source.en.md`.
3. Заполнить свою строку в `../SCREENING_RESEARCHER.tsv`.
4. Не смотреть решение Codex до завершения независимого прохода.
5. После раскрытия расхождений заполнить `../ADJUDICATION.tsv`.
