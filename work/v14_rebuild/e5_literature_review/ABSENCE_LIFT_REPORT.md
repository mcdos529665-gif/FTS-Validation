# Отчёт проверок типизированного отсутствия и проекта Lift

- Статус проверок: `candidate_probe`, не C-NN.
- Арифметика риска: точные рациональные числа `Fraction`.
- Область: конечные записи, множества и паспортные условия.
- Влияние на `St_FTS`: отсутствует.

Команда:

```powershell
python -X utf8 work/v14_rebuild/e5_literature_review/check_absence_lift_projects.py --write-report
```

Результат:

```text
PASS TA-01 — Одна булева тень допускает разные механизмы и provenance: Две различные записи отображаются в одно событие absent(A@ℓ).
PASS TA-02 — Проекция event/Tot необратима на выбранном волокне: Мощность волокна 2, мощность булевого образа 1; декодера нет.
PASS TA-03 — Sever разрывает непрерывность provenance: До удаления путь sensor→model_input непрерывен, после удаления ребра — нет.
PASS TA-04 — Проверенный механизм может дать операциональный выигрыш: Риск булевой тени=1/2; риск типизированного механизма=0.
PASS TA-05 — Неинформативная метка не подтверждает AbsDataGain: Постоянный unknown сохраняет риск 1/2; прироста нет.
PASS LT-01 — Set-кандидат сохраняет старый слой: Для ι(x)=(x,r₀) точно выполнено π∘ι=id_X.
PASS LT-02 — Остаточное чтение не факторизуется через старый слой: ρ различает r₀ и r₁ в одном π-волокне.
```

TA-01…TA-05 подтверждают необратимость булевой проекции, локальный эффект provenance и ограниченный пример выигрыша. LT-01…LT-05 подтверждают только конечную Set-модель и выявленные предпосылки. Проверки не канонизируют запись `0_A`, не доказывают общий Lift и не устанавливают WFS.
