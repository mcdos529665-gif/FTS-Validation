## 0. Гардрейлы

- **Z/2 ≠ U(1)** (`Rot ≠ −`): лемма живёт на ИНВОЛЮЦИИ (зеркало ветви /
  аргумента / сопряжение). Фазу θ∉{0,π} как непрерывный канал она НЕ покрывает —
  только её дискретный след (бит полуплоскости). Смешать = выдать Д10 за Д11.
- Школьный дискриминант `D` ≠ «дискриминант» C-59 (единичная граница —
  внутренний термин v14).
- Три отрицания не смешивать: лемма — про анти-форму/ветвь (`−`, Z/2), не про
  `¬A` (булев флаг) и не про `⊖A` (антимода-отказ 7+).
- Лемма — candidate; PASS ничего не повышает; таблица §3 даёт пунктам
  тест-спецификации, НЕ вердикты. Прошедшее спецификацию остаётся candidate
  до собственного свидетеля (К1–К5).
- [внешнее]: теорема о симметрических функциях (симметричный полином от корней
  выражается через элементарные симметрические); факт «антисимметричный полином
  пары делится на разность». Канон-/v14-грунт: лемма Tot (коллапс `Z/2→{1}`,
  формализация О2), зеркальное окно `{F,−F}` [ADD_MIRROR_WINDOW/SP_WINDOW],
  чётность [C-05], Q-канал [C-40], Д11-бит `x/|x|=sign(x)` (регистр отношений),
  V·V пары [C-61 deg56], нулевая граница [SP_ZERO], двухканальность A3.

## 1. Лемма (формулировка)

Носитель — **зеркальная пара** с инволюцией σ (Z/2): пара корней `{r₁,r₂}`
(σ = обмен ветви `√D→−√D`), аргументное зеркало `{x,−x}` (σ: `x↦−x`),
сопряжённая пара `{z,z̄}` (σ = сопряжение, Gal(ℂ/ℝ)=Z/2).

Любой функционал `f` от пары разлагается **единственно**:

    f = f_sym + f_anti,   σ(f_sym) = f_sym,   σ(f_anti) = −f_anti
    f_sym = (f + σf)/2,   f_anti = (f − σf)/2

- **(а) ТЕНЬ.** `f_sym` выражается через Agg-агрегаты пары (для корней —
  `e₁=r₁+r₂, e₂=r₁·r₂` [внешнее: симметрические функции]; для `{x,−x}` —
  чётная часть, функция `|x|`/`x²`; для `{z,z̄}` — `Re` и `|z|²`).
  ФТС-чтение: тень = ровно **инварианты коллапса Tot** `Z/2→{1}` [лемма Tot] —
  то, что выживает тотализацию ветви; агрегат Ч-регистра слеп к ветви.
- **(б) БИТ.** `f_anti` кратна базовой разности (`r₁−r₂ = ±√D` / `2x` /
  `2i·Im z`) — поверх тени она несёт ровно **один бит** (какая ветвь).
  Тень его не содержит: бит невосстановим из симметричных агрегатов
  (VIETA-5, PAR, D2, SHADOW-4).
  **Уточнение 2026-09-09:** речь о двухэлементной орбите и детекторе, для
  которого `f_anti≠0` на этой орбите. Нулевой отклик конкретного детектора
  не позволяет восстановить бит. Для полиномов кратность разности —
  полиномиальная; общего класса произвольных функций этим не задаём.
- **(в) КВАДРАТ.** `f_anti²` — снова тень; для базовой разности это
  `D=(r₁−r₂)²` = **V·V пары** [C-61 deg56-паттерн]: стёртое различие
  возвращается вниз только квадратом (знак потерян).
- **(г) НУЛЕВАЯ ГРАНИЦА.** На диагонали `r₁=r₂` всегда `f_anti=0`.
  Обратное верно для базовой разности `d=r₁−r₂`, но не для произвольного
  детектора. Для вещественного полинома
  `f_anti=(r₁−r₂)h(r₁,r₂)`, где `h` симметричен, поэтому
  `Z(f_anti)={r₁=r₂}∪Z(h)` [внешнее; PA-F09/C28]. Дополнительные нули
  `h` вне диагонали — слепота считывания, а не схлопывание пары.
  Пример: `f=r₁²`, `(r₁,r₂)=(1,−1)` даёт `f_anti=0`, но `d=2`.
  [SP_ZERO] сохраняется для самой формы; он не утверждает инъективность
  произвольного детектора. Прежнее общее «ровно» снято:
  [EC-005](../EXTERNAL_CONFLICTS.md#ec-005),
  [NC-04 и пробы NC-P11…13](NEW_CONNECTIONS_2026-09-09.md#nc-04).

**Следствие-гейт (сцепка с QG [O_14]):** различающий ход канала бита (Д11)
может жить ТОЛЬКО в `f_anti`. Если целевой функционал симметричен
(`f_anti=0`) — ход воспроизводим из тени при равной цене ⇒ **QG-fail**;
если антисимметричная компонента ≠ 0 — тень её в принципе не выражает
(SHADOW-5). QG говорит «предъяви ход», тень-лемма говорит «единственное
место, где он может жить».

## 2. Инстансы класса (что замкнула Виета)

| инстанс | зеркало σ | тень (инварианты) | бит (антиинвариант) | свидетель |
|---|---|---|---|---|
| PAR «минус из равенства» | `x↦−x` | чётные формы `\|x\|,x²,…` [C-05] | знак `x` (нечётная часть) | PAR-1…4 |
| D2 sign-retrieval | `a↦−a` | `\|a\|`+контекст | `sign(a)` — не восстановим при равной цене | QG-2 (worked-neg) |
| VIETA | обмен ветви `√D` | агрегаты `e₁,e₂` | какой корень; `(r₁−r₂)=±√D` | VIETA-1…5 |
| Д10/Д11-след | сопряжение `z↦z̄` | `Re z`, `\|z\|²` (Q-канал [C-40]) | `sign(Im z)` — бит полуплоскости | SHADOW-4 |

Четыре записи одного разложения — это и был скрытый класс; до Виеты
инстансов было два (PAR, D2) и класс не был виден.

## 4. Что закрывает / что остаётся

- **Закрывает** (для пула разом): мета-вопрос П5 «в КАКОЙ компоненте искать
  различение» — как QG закрыл для П4 «по какому критерию судить». Сужает
  поиск площадок: d11 и d2-остаток — антисимметричные цели; Д10 — только
  U(1)-ядро.
- **Не закрывает**: ни один тест П5 не прогнан; U(1)-содержание Д10 вне
  леммы; `oq-forms8plus-ratio` не покрыт; статусы (в т.ч. потолок SP_COMPLEX)
  не двигаются.
- **Условия поражения (К1):**
  1. *операциональное* — площадка, где бит восстановим из чистой тени ПРИ
     РАВНОЙ ЦЕНЕ (убивает чтение «бит = отдельный канал Д11»; алгебраически
     бит невосстановим — SHADOW/VIETA, но реальная задача может дать боковой
     канал восстановления, как контекст в D2);
  2. *декоративность* — если ни один П5-тест не изменил форму после леммы,
     лемма ничего не структурирует. Уже НЕ выполняется: d11 получил точную
     форму, Д10 — вычет дискретного следа (см. OPEN_QUESTIONS).
  Алгебраическое ядро (разложение/выразимость) — [внешнее], опровержению
  внутри ФТС не подлежит и претензией НЕ является; претензия леммы — только
  ФТС-чтение (тень=Tot-инварианты) и полезность спецификаций.
