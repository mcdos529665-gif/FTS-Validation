## 1. Склейка МУ6/МУ7 и поворот на 90° [C-100]

**[автор]** Склейка `y=√|x|` с `y=−√|x|` даёт параболы, повёрнутые на 90°.

- Пара МУ6∪МУ7 — множество `|y|=x²`; пара МУ8 с анти-формой — `y²=|x|`
  (кандидат C-76). Поворот на ±90° и перестановка `x↔y` переводят первое множество
  во второе и обратно.
- Одна МУ8 `y=√|x|` — только верхние половины двух боковых парабол; целая боковая
  парабола получается лишь из пары.
- Крест `|y|=|x|` при повороте на 90° переходит в себя. Как множества
  МУ2∪МУ3 = МУ4∪МУ5 = `|y|=|x|`; различие 2/3 и 4/5 держится на том, какие половины
  склеены (согласуется с Д2 «удержание пары У2/У3»).
- **[автор]** Предложено читать нижние уровни через поворот: `y=x` → `y=−x` → склейка →
  `|x|` → `−|x|`. Счёт: поворот на 90° даёт противоположность `y=−f(x)` только для
  прямой `y=x`; поворот на 180° — только для чётных форм (`|x|`, `x²`, `√|x|`); для `x³`
  не подходит ни один. Склейка `y=x` и `y=−x` даёт крест, а не `|x|`; `|x|` требует
  выбора половин. Противоположность всем формам даёт только зеркало `y↦−y` (минус, Д1).

**Предложение (не принято):** минус — противоположность внутри уровня; шаг
МУ6/МУ7 → МУ8 читать как обращение (`x↔y`, корень обратен квадрату). На всех
склеенных парах поворот на 90° и `x↔y` дают одно множество, поэтому данные выбрать
поворот не могут. У обращения есть опоры: МУ8 как обратный ход квадрата
(`FTS_v14_register_map.md:151`; Д4 «корень возвращает пару»); МУ6 и МУ8 совпадают в
0 и ±1, а соседи МУ7 и МУ8 в единице противоположны — как требуют связи +2 и ±1
(C-57, C-58). Предел: ниже 7 переход нового не даёт, пара МУ8 возвращается к МУ6/МУ7,
пара МУ9 уходит в кубические корни, которых в лестнице нет. OQ
`oq-mu8-inverse-vs-rotation`.

## 2. МУ9 и правило противоположности

По правилу «с 7 противоположность внутри» запрет `y≠−x³` (`FTS_v14_register_map.md:72`)
следовало бы снять и записать пару `|y|=|x|³`. Но пара стирает знак (в ней `(1,1)` и
`(1,−1)`), а смысл МУ9 — возврат направления `sign(x³)=sign(x)`
(`FTS_v14_paper.md:962–966`); канон называет потерю направления на У9 условием
поражения (`FTS_v14_paper.md:1771–1774`).

**Предложение (не принято):** запрет в МУ9 оставить; противоположность входит в МУ9
множителем: в `x·x²` множитель `x²` несёт склеенную пару снизу, `x` выбирает ветвь.
Решение за автором: OQ `oq-mu9-opposite-inclusion`.

## 3. Двойка [C-101]

**[автор]** Вопрос: есть ли что-то особое при подстановке 2; «8 — это двойка в кубе».

- `x+x = x·x` ⟺ `x∈{0,2}` **[внешнее]**. Рядом с границами канона (0: `F=−F`;
  1: `F·F=F`, `FTS_v14_register_map.md:212–217`) двойка — точка, где сложение и
  умножение совпадают.
- При x=2 умножение на x есть удвоение: МУ6 = МУ2+МУ2 (4=2+2), МУ9 = МУ6+МУ6 (8=4+4);
  МУ2, МУ6, МУ9 дают 2, 4, 8 = 2¹, 2², 2³ — числа состояний одного, двух, трёх битов
  (V4 у троек; `(Z/2)³` окна 25).
- Окружность МУ12 с представителем `r=2` имеет длину = площади (4π) ровно потому, что
  `2r=r²`; канон держит это совпадение как analogy_only (`FTS_v14_paper.md:1574–1576`).
- 2 — первая точка после опор 0 и 1, где формы, совпадающие в 0 и 1, расходятся
  (уже отмечено: `e5_literature_review/dr_core_2026-09-11/inputs/DR-08_O_08_Two_Step_Projection.md:260`).

Граница: в двойке любая степень даёт 2ⁿ, поэтому совпадение с группами окон числовое.

## 4. Правило среды как подстановка номера [C-102]

**[автор]** Подставить в формулу МУn номер предыдущего уровня, `x = n−1`, по правилу
О1; семёрка для МУ8 выбрана этим правилом до счёта. **[автор]** МУ2 при x=1 задаёт
принцип счёта как таковой.

- МУ2(1)=1, МУ3(2)=−2, МУ4(3)=±3, МУ5(4)=−4: правило воспроизводит счёт 1, 2, 3, 4 со
  знаком, чередующимся с уровнями. С МУ6 счёт обрывается: МУ6(5)=25, МУ7(6)=±36,
  МУ9(8)=512. Совпадает с каноном «различимость 3–5 по знаку, 6+ по масштабу»
  (`FTS_v14_register_map.md:216–217`), но оба вывода следуют из линейности форм МУ2–МУ5,
  поэтому это согласованность, не независимое подтверждение.
- МУ8 в форме `y⁴=x²` (C-76) над C при x=7 даёт `±√7, ±i√7`; `i√7 = √−7` — число окна 15
  (`windows_table.tsv`, строка 15; смысл открыт: `oq-windows11-15-quadratic-meaning`).
  Минус приходит из формы, а не из подстановки −7.
- **[внешнее]** `2 = ((1+√−7)/2)·((1−√−7)/2)`: в кольце с `√−7` двойка распадается на две
  сопряжённые половины, потому что `−7 ≡ 1 (mod 8)`; −7 — первое такое отрицательное
  бесквадратное число. `7 = 2³−1` — ненулевые метки трёх битов (точки Фано);
  `|GL(3,2)| = |PSL(2,7)| = 168` (изоморфизм — классический факт, проверены порядки).
- Контроль подгонки: сдвиги `x=n+k`, k=−3…+2, дают 2–3 совпадения с таблицей окон;
  k=−1 и k=+1 дают по 3. По числу совпадений правило не выделяется; МУ8 даёт корень
  какого-либо окна при любом x из 1, 2, 3, 5, 7. Сила случая — выбор семёрки правилом
  до счёта. OQ `oq-o1-environment-substitution`.

- **[внешнее]** Треугольник Паскаля mod 2 строится из одной единицы, каждая строка только

## 6. МУ9 и проекции [C-104]

**[автор]** «9 уровень — уровень проекций? Если две противоположные точки дают ссылку,
то три точки дают проекцию?» В проекте утверждения «СУ9 = проекции» не было: СУ9 —
Понимание; карточка `M_09` = `Analogy_κ(...)/TBD`; открыт вопрос о ребре `projects_to`
9→7 (`OPEN_QUESTIONS.md`, `oq-minimal-windows-projects-to`).

- МУ6 пересекает МУ2 (`x²=x`) в двух точках 0, 1. МУ9 пересекает МУ2 (`x³=x`) в трёх:
  −1, 0, 1 — пара противоположностей и центр 0; это первое минимальное окно `(−1,0,1)`.
- **[внешнее]** Всякий `t` с `t³=t` есть разность ортогональных проекций `t = P−Q`, и
  `t² = P+Q` — проекция. МУ9 на трёх точках держит две проекции с противоположными
  знаками; квадрат (МУ6) даёт обычную проекцию. Возвращённый знак МУ9 `sign(x)`
  принимает ровно значения −1, 0, 1.
- **[внешнее]** В плоскости Фано любые две точки a, b дают третью `a⊕b` (снова `a≠b`), и
  тройка — прямая: «две точки дают ссылку, вместе с ней три — прямая».
