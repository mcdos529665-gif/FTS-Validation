# Экспорт-стейджинг v14 — машинно-готовые фрагменты статус-патча

Это **НЕ канон.** Канон в `source/` неизменяем и генерируется ВНЕШНЕ: xlsx-воркбук →
export-пайплайн → 13 файлов + `MANIFEST.json` с SHA256. Собственно **сборка v14-выгрузки**
(новый воркбук → экспорт → новый MANIFEST) — **авторский/внешний шаг**; её нельзя честно
собрать правкой файлов (сломает `tools/verify.py` и нарушит неизменяемость).

Что здесь: точная спецификация того, что КАЖДАЯ v14-карточка статус-патча ДОБАВЛЯЕТ в дамп,
в той же схеме, что `source/` — чтобы авторский экспорт применил их детерминированно, без
ручной интерпретации prose-таблиц `status_patch_v14.md`.

## Файлы
- `v14_export_cards.jsonl` — карточки в схеме `source/fts_cards.jsonl`
  (`id,type,text,depends_on,tags,path,status,internal_ref,symbol,title`).
- `v14_export_triples.tsv` — рёбра в схеме `source/fts_triples.tsv` (`subject⇥predicate⇥object`;
  предикаты из существующего словаря: `depends_on`, `promotes_status_of`, `does_not_promote_above`).

## Механизм (как в v13-дампе)
SP-карточки УЖЕ есть в каноне (SP_WINDOW/SP_ZERO/SP_U8/SP_U9/SP_U12) и работают через
`SP_* → promotes_status_of → *`. При применении целевая карточка принимает статус из ПОЛЯ
`status` самой SP-карточки. Новые v14-карточки следуют ровно этому шаблону.

## Застейджено
- **SP_STRICT_BAND_7** (пункт `oq-strict-band-7-export`, решение Б 2026-07-09): граница
  твёрдого ядра по ФОРМАМ до У7. Частичность («семантика У7 НЕ повышается») закодирована в
  СТРОКЕ `status` — по образцу составного статуса SP_U12 («candidate_requires_formalization +
  canonical_alignment»), — а НЕ отдельным `does_not_promote_above` (нет чистого узла
  «семантика У7», и такое ребро противоречило бы `promotes_status_of` на уровне сырого триплета).

Остальные карточки `status_patch_v14.md` §1/§2 стейджатся сюда идентично по мере заморозки
теории (пока не внесены — теория активна).

## Провизорные поля (на подтверждение автора при сборке воркбука)
- `path`: `45_Статус_гипотез_v14/SP_STRICT_BAND_7` — финальный лист задаёт автор (v13-SP лежат
  на листе `45_Статус_гипотез_v9`).
- `internal_ref`: `V14_STATUS_PATCH` — честное происхождение (не `RESEARCH_STATUS_V9`).
- Кодировка частичности статусом-строкой (см. выше) — если автор предпочтёт отдельный
  guardrail-узел «U7-семантика/гейт», ребро добавляется тогда.

## Проверка после сборки
Внесённая в воркбук карточка обязана round-trip’ить: `tools/verify.py` → 0 mismatch;
`tools/query.py card SP_STRICT_BAND_7` показывает её со `promotes_status_of → U_07`.
