# Аудит второй площадки для операционального теста Д10

Дата: 2026-07-13. Статус: исследовательский аудит `[внешнее]`; канон, статья v14,
статусы и потолок `SP_COMPLEX` не меняет.

## Найдено

Под общим ярлыком «вторая площадка» смешивались два разных открытых набора:

1. **Benchmark 35×40** `[внешнее]`: 35 субъектов, 40 целей, 64 канала, 6 блоков.
   Частоты 8–15.8 Гц с шагом 0.2 Гц; разность фаз между соседними частотами 0.5π.
   Источник: https://pubmed.ncbi.nlm.nih.gov/27849543/
2. **Wearable 102×12** `[внешнее]`: 102 субъекта, 12 целей, 8 каналов, по 10 блоков
   для мокрых и сухих электродов. Частоты 9.25–14.75 Гц с шагом 0.5 Гц; разность
   фаз между соседними частотами 0.5π.
   Источник: https://www.mdpi.com/1424-8220/21/4/1256
   Данные: https://doi.org/10.6084/m9.figshare.13560281

Общий критический факт: в обоих дизайнах каждой цели назначена своя частота, а фаза
детерминированно меняется вместе с частотой. Пар «одно `f`, разные `φ`» нет. Прежняя
запись CANDIDATES «соседние цели одной частоты различаются фазой» фактически неверна.

## Аудит происхождения формул

| Формула из обсуждения | Что есть в источнике | Допустимое чтение ФТС |
|---|---|---|
| ITR | Да, формула (2) wearable-статьи | Тематическая метрика результата; нового равенства лестницы нет |
| `y_{f,φ}` / sampled sinusoid | Формула (1) задаёт дискретную яркость стимула с `f,φ` | Носитель внешнего эксперимента, не доказательство Д10 |
| `x_c(t)=Σ A sin(...) + n` | Такой точной генеративной формулы в статье нет | Внешняя модель сигнала; не приписывать источнику |
| CCA `ρ` | Метод используется, но эта точная формула не является формулой статьи | Корреляционная статистика; после квадрата Q-подобное чтение У6 |
| `R=Σw_bρ_b²` | Относится к исходной методике FBCCA | `ρ²` + взвешенный `Agg`; не фазовый TEST |
| PLV | В статье отсутствует | Модуль резольтанты: null для глобального фазового угла, не Д10-test |
| `S=αρ+β·PLV` | В статье отсутствует; отдельный источник не установлен | Не выдавать за опубликованную формулу или полярное разложение |

Методический источник FBCCA: https://pubmed.ncbi.nlm.nih.gov/26035476/

## Математический гардрейл

Для частоты `f` и фазового референса `φ` положим

`Z_{f,φ} = (1/T) Σ_t exp(i(φ_EEG(t) − 2πft − φ))`.

Если `φ_EEG(t)=2πft+θ₀`, то

`Z_{f,φ}=exp(i(θ₀−φ))`, поэтому `|Z_{f,φ}|=1` при любом `φ`, а
`arg Z_{f,φ}=θ₀−φ`. Следовательно:

- PLV=`|Z|` измеряет силу фазовой согласованности, но инвариантен к постоянному
  глобальному фазовому сдвигу. Для задачи «абсолютная фаза как код» это законный
  Q-подобный null [C-40], а не TEST Д10. Он не «полностью бесфазовый»: временную
  согласованность фаз сохраняет.
- Значение фазового кода несут `arg Z` либо пара `(Re Z, Im Z)`; угол надёжен только
  при достаточно большом `|Z|`.
- `arg(z[t+1]·conj(z[t]))` уничтожает постоянную `θ₀` и измеряет приращение фазы /
  мгновенную частоту. Эту статистику нельзя использовать как тест начального кода.
- Пары `sin(2πnft), cos(2πnft)` в CCA порождают одно и то же подпространство после
  постоянного фазового поворота. Максимизированная `ρ`, её квадрат и FBCCA-агрегат
  поэтому не свидетельствуют сами по себе, что декодер использовал абсолютную фазу.

Это конкретизация существующего гардрейла `Rot ≠ −` и Q/ratio-разведения, а не новая
формула лестницы и не основание для повышения статуса.

## Вердикт для Д10

Обе площадки пригодны для слабого контраста представлений:

- **TEST:** `arg Z`, `(Re Z, Im Z)` либо фазово-выровненный
  `Re(exp(−iφ_k)·Z_k)` при сохранении одинаковых частотных/гармонических признаков;
- **NULL:** `|Z|`/PLV и те же частотные/гармонические признаки, равная ёмкость модели;
- **контроли:** фазовое перемешивание/временной сдвиг с сохранением спектра,
  одинаковые окна, парная оценка по субъектам и типу электродов.

Но возможный выигрыш означает только «фазочувствительное представление помогает при
совместном кодировании `(f,φ)`». Он не доказывает независимую необходимость фазы,
поскольку target-ID уже восстанавливается из уникальной частоты.

Для сильного Д10-теста требуется факторный дизайн: одно и то же `f` при нескольких
независимо назначенных `φ`, либо рандомизация соответствия фаз целям/испытаниям.
До появления такой площадки вопрос `oq-d10-phase-test` остаётся открыт, линия Д10 —
припаркована, потолок `SP_COMPLEX` — без изменений.
