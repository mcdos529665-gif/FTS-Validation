Протокол: руководство runbook_complex_axis.md фазы 2–4.

## Гипотеза и область

**H1 (основная):** Модель с непрерывной фазой (полярное/комплексное представление z = r·e^{iθ})
превосходит null-модель (декартово с тенью: {|z|, Re(z)} + дискретный бит sign(Im(z)))
на задачах с **композицией вращений** при равной ёмкости. Композиция означает: результирующая
волна = сумма двух или более волн с независимыми фазами; фазы складываются по U(1)-закону.

**H0 (null):** Разницы нет; преимущество не воспроизводится; обе представления эквивалентны
при равной цене.

## Площадка Д10: синтетическая волновая интерференция

### Выбор по чек-листу §4

1. **Фазовая структура документирована предметной областью [внешнее]:**
   - Волновая интерференция в классической физике и оптике [внешнее: волновая природа света,
     суперпозиция амплитуд].
   - Композиция: E(t) = A₁·cos(ωt + θ₁) + A₂·cos(ωt + θ₂). В комплексной форме:
     z = A₁·e^{iθ₁} + A₂·e^{iθ₂}. Фазы θ₁, θ₂ — управляемые параметры.
   - Источник: фундаментальная физика, модель стандартна и открыто документирована [внешнее].

2. **Есть композиция/динамика, где фазы складываются:**
   - Результирующая волна получается суммой: z_result = z₁ + z₂.
   - Величина |z_result| и аргумент arg(z_result) зависят нелинейно от θ₁, θ₂.
   - Интерференция создаёт конструктивные/деструктивные эффекты в зависимости от фазового
     сдвига Δθ = θ₁ − θ₂. Это и есть вращательная динамика.

3. **Null имеет честный шанс (равная архитектура и бюджет):**
   - Тестовая модель получает вход: (real, imag) — два вещественных числа.
   - Null-модель получает: (|z|, Re(z), bit_sign) — ровно три значения:
     * |z| = √(real² + imag²)
     * Re(z) = real
     * bit_sign = sign(imag) ∈ {−1, 0, +1} → дискретный бит (закодирован одной фичей)
   - Обе восстанавливают Im(z) = bit_sign · √(|z|² − Re(z)²). Null и test имеют ту же информацию.
   - Архитектура: линейная модель (LogisticRegression) для бинарной классификации. Параметры
     и трудозатраты равны для обеих. Фазовое представление НЕ даёт extra-параметров.

4. **Контроль специфичности: парная задача без вращательной структуры.**
   - **Ротационная задача (test vs null):** В комплексном представлении точку можно описать как
     z = r·e^{iθ}. Модель должна обучиться предсказывать целевую функцию f(r, θ), которая нелинейна
     по θ (например, f ∝ sin(θ) или f ∝ cos(θ − θ₀)).
   - **Контрольная задача (test vs null, ожидаем null выиграет):** Гауссово облако точек в ℝ² без
     структуры вращения. Целевая функция f(x, y) = линейная комбинация или гауссовский процесс
     (обе модели одинаково хороши). На этой задаче фазовое представление не должно выигрывать.
   - Если test выигрывает на обеих → не про вращение, а про общие полярные координаты → не
     засчитывается.

5. **Данные реальные или синтетические, достаточный объём для парного теста (≥4 задачи/датасета):**
   - Сгенерируем локально в Python:
     * **Tasks (ротационные):** интерференция (синус результирующей фазы), спектр мощности (косинус),
       угловая скорость (производная фазы).
     * **Control (гауссовы облака):** n точек, y = a·x₁ + b·x₂ + ε, n точек, y = exp(−||x||²).
     * Каждая задача: n=1000 примеров; бинарная классификация (пороговое разделение).
   - Достаточно: 4 ротационные + 2 контрольные = 6 задач.

## Модели и бюджет параметров

**Архитектура:** `LogisticRegression(penalty='l2', C=1.0, solver='lbfgs', max_iter=2000)`.

**Тестовая модель (фазовая):**
- Вход: `[real, imag]` (2 фичи).
- Масштабирование: StandardScaler.
- Параметры: (2+1) = 3 (веса + bias).

**Null-модель (декартова с тенью):**
- Вход: `[abs_z, real, bit_sign]` (3 фичи).
  * `abs_z = √(real² + imag²)`
  * `real = real`
  * `bit_sign = sign(imag)` [дискретно закодирован как вещественное −1, 0, +1]
- Масштабирование: StandardScaler.
- Параметры: (3+1) = 4 (веса + bias).

**Уравнивание ёмкости:** Null получает 4 параметра, test — 3. Дополнительный параметр null —
это «компенсация» за мультиколлинеарность (|z|, real уже не независимы). При равных попытках
тестовая модель меньше и должна проигрывать, если вращение несущественно.

Сиды: SEED = 20260709 (детерминированно).

## Метрика и первичный контраст

**Метрика:** ROC-AUC на тестовой доле (RepeatedStratifiedKFold, 5 splits × 4 repeats = 20 фолдов).

**Первичный контраст:**
- Ротационные задачи: `AUC(test) − AUC(null)` попарно по фолдам, 4 задачи × 20 фолдов = 80 пар.
- Объединённый парный тест Wilcoxon signed-rank (односторонний, тест > null): α = 0.01 (строго,
  как в runbook).
- **Критерий PASS (H1):**
  * **На ротационных задачах:** test > null статистически значимо (p < 0.01) и по медиане
    ΔAUC > +0.03 (минимальный практический прирост);
  * **На контрольных (гауссовы облака):** test ≈ null (p > 0.05 или направление не определено).
- **Критерий FAIL (H0):** Иначе — если test не превосходит null на ротационных, или если
  test выигрывает также на контрольных (нет специфичности).
- **UNCLEAR:** Контроль грязный (есть эффект на обоих типах), или нестабильно по сидам.

## Оговорки (заранее)

- **Синтетика vs реальность:** Синтетические данные НЕ покрывают весь спектр "реальной" композиции
  (например, каналы связи, обработку сигналов реального времени). PASS означает, что вращение
  дало роль на синтетике; реальная сила роли требует дополнительных площадок (оставляется
  на будущее).
- **Утечка информации:** Проверяется, что null получает бит sign(Im) — БЕЗ непрерывной фазы θ.
  Если окажется, что null привёл к фазовому каналу — тест мёртв (SHADOW-4 нарушен).
- **Нестабильность по сидам:** Если результат чувствителен к выбору SEED или разделению фолдов —
  это указывает на слабость эффекта. Фиксируем один SEED и один run.
- **Баланс классов:** Все задачи генерируются с балансом 50/50 для простоты.
