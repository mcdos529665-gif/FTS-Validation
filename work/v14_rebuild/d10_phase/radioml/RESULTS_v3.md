## Диагноз: враппинг фазы при π-скачках модуляции

CFO-нормализация `z'_t = z_t · exp(−i·m̂·t)` убирает линейный дрейф фазы из комплексного
сигнала z. Теоретически для чистого тона `z_t = A·exp(i·(ω·t + φ₀))` → `Δφ'_t = 0`.

Для **PSK-сигнала с π-скачками** (BPSK кодирует данные скачками ≈ ±π) математика разрушается:

    Δφ'_t = angle(z'_{t+1} · conj(z'_t))
           = angle(z_{t+1} · conj(z_t) · exp(−i·m̂))

В отсутствие враппинга: `= Δφ_t − m̂`, и `mean(Δφ'_t) = m̂ − m̂ = 0`. ✓

При ВРАППИНГЕ (π-скачки BPSK): `angle(·)` живёт в (−π, π] и НЕ является аддитивным.
`angle(exp(a)·exp(b)) ≠ angle(exp(a)) + angle(exp(b))` когда сумма выходит за (−π, π].

Диагностика на примере 76 (BPSK, m̂ = −0.2945):
- 77 из 128 временных шагов имеют |Δφ| > π/2 (π-скачки модуляции)
- mean(Δφ') = −0.2945 = m̂ (нормализация ничего не дала)
- Поэлементный и батчевый расчёт дают одинаковый результат → ошибка в концепции, не в коде

Это ФИЗИЧЕСКОЕ свойство PSK-данных, предсказуемое аналитически:
- Δφ_t для BPSK ≈ {-π + noise, 0 + noise} (биполярные прыжки)
- mean(Δφ_t) ≈ m̂ ≠ 0 потому что -π + noise < -π/2, и wraparound делает эти значения ≈ +π
  фактически. Распределение Δφ двумодальное и не центрировано.
- Дероутация z*exp(-i*m̂*t) сдвигает МОДУЛЯЦИОННУЮ структуру, но не убирает m̂ из wrapped Δφ.

В результате «нормализованное» Δφ' несёт ТОТ ЖЕ m̂ (или близкое) скалярный сигнал, что и в v2.
Вычитание артефакта не выполнено.
