## Гейт-апробации §3 runbook_complex_axis (письменно, до прогона)

1. **Подаётся ли непрерывная фаза в TEST-модель?**
   ДА — TEST получает Δφ'_t = angle(z'_{(t+1) mod 128} · conj(z'_t)), где z'_t = z_t·exp(−i·m̂·t)
   — непрерывный угловой ряд приращений фазы (128 чисел в (−π, π]). Это НЕ сырые (I,Q) и НЕ
   декартовы координаты; z' дероутирована на оценку несущей m̂ = mean_t(Δφ_t). Гейт прошёл.

2. **Восстановим ли таргет из одного бита sign(Im) или аналогов?**
   НЕТ — таргет = порядок PSK-созвездия (BPSK/QPSK/8PSK = 3 класса). Различение 2, 4 и 8
   точек требует количественной информации о фазовом интервале (π, π/2, π/4). Ни sign(Im z'),
   ни sign(Re z'), ни знак любого одного проекционного бита не различает 3PSK-класса при
   рандомизированной абсолютной фазе. Гейт прошёл.

3. **Нужна ли θ тоньше полуплоскости?**
   ДА — 8PSK имеет созвездие с шагом π/4 << π; различение QPSK (шаг π/2) от 8PSK (шаг π/4)
   требует разрешения угла тоньше π/2 (т.е. тоньше одного бита полуплоскости). Непрерывные
   приращения Δφ'_t несут эту информацию; sign(Δφ'_t) не несёт (дифференциальный бит — NULL-B).
   Гейт прошёл.

Все три гейта дают ответ «фаза реально в тесте и реально нужна». Прогон разрешён.

## CFO-нормализация (ключ v3)

Для каждого примера z = I + i·Q (форма (2,128), I=канал 0, Q=канал 1, t=0..127):
1. Δφ_t = angle(z_{(t+1) mod 128} · conj(z_t));  m̂ = mean_{t=0..127}(Δφ_t).
2. Дероутация: z'_t = z_t · exp(−i · m̂ · t),  t = np.arange(128).
3. ВСЕ признаки ВСЕХ моделей (TEST, NULL-A, NULL-B, SCALARS, абляция) строятся из z'.
4. Машинная проверка нормализации: пересчитанный mean_{t}(Δφ'_t) по каждому примеру < 1e−6
   по абсолютной величине (assert в скрипте).
   — Если max|mean Δφ'| в диапазоне 1e-6..1e-3: записать факт в RESULTS и продолжать.
   — Если max|mean Δφ'| > 1e-3: СТОП, АРТЕФАКТ, вердикт не выносится.

Симметричность: артефакт lo_mean (класс-коррелированная средняя мгновенная частота) вычтен из
обеих сторон одновременно, поэтому контраст TEST vs NULL изолирует только повременную непрерывную
фазу, а не скалярный offset.

## Модели (равная ёмкость: 256 признаков на пример, одна MLPClassifier((hidden,), max_iter=300))

- **TEST:**   [|z'_t| (128); Δφ'_t (128)] — нормализованная тень + непрерывные приращения фазы.
- **NULL-A:** [|z'_t| (128); sign(Q'_t) (128)] — канонический тень+бит (shadow_lemma).
- **NULL-B:** [|z'_t| (128); sign(Δφ'_t) (128)] — дифференциальный бит (сильнейший null).

Примечание: все три модели используют z' (нормализованные данные), так что контраст чистый.

**SCALARS-абляция (проверка «дешевизны», НЕ null для вердикта):**
10 признаков: [std(Δφ'), mean(|Δφ'|), histogram(Δφ', bins=8, range=(−π,π], density=True)].
Оценивается при hidden=64. Если TEST(64) − SCALARS < +0.05 → роль фазы исчерпывается
распределительными статистиками (PASS-С, не PASS-Т).

**m̂'-абляция:**
1 признак: [m̂'] = пересчитанная средняя Δφ' ПОСЛЕ дероутации (должна быть ≈ 0 по всем примерам).
Оценивается при hidden=16. Ожидание: < 0.40 (поле 0.333). Если > 0.40 — новый скалярный артефакт, СТОП.

## Задачи и замороженные параметры (унаследованы от v2, НЕ менять)

- РОТАЦИЯ: {BPSK, QPSK, 8PSK} (вращательная структура, фаза предметно обоснована).
- КОНТРОЛЬ: {PAM4, AM-DSB, AM-SSB} (без вращательной структуры; там фаза НЕ должна выигрывать).
- SNR ≥ 10 (срезы 10, 12, 14, 16, 18 дБ).
- cap = 2000 примеров/класс; seed = 20260709.
- hidden ∈ {8, 16, 64, 256}; StandardScaler fit на train-fold; метрика: accuracy.
- Кросс-валидация: RepeatedStratifiedKFold(n_splits=5, n_repeats=4, random_state=seed) = 20 фолдов.
- Парный тест: Wilcoxon односторонний (test > null) по 20 фолдам.

## Критерий (заморожен ДО прогона; §4 runbook_v3 дословно)

«Победа на ёмкости h» := p < 0.01 И медиана Δacc > +0.05 (против ОБОИХ null'ов A и B).

**PASS-Т (темпоральная роль):** победа на ВСЕХ h ∈ {8,16,64,256}; И TEST(h=64) − SCALARS ≥ +0.05
(парный Wilcoxon p < 0.01); И контроль чист; И m̂'-абляция мертва (1 признак при h=16: acc < 0.40).

**PASS-С (скалярная роль):** победа на всех h, контроль чист, НО TEST(64) − SCALARS < +0.05 —
роль фазы есть, но исчерпывается распределительными статистиками. Для потолка слабее; так и писать.

**OVERLAY-СОГЛАСНО:** победа при h=8, но хотя бы один null догоняет к h=256 → потолок стоит.

**FAIL:** нет победы над обоими null'ами при h=8, или контроль грязен.

**Контроль чист** := на КОНТРОЛЕ test не превосходит НИ ОДИН null: медиана Δ < +0.03 ИЛИ p > 0.05,
для всех h.

**АРТЕФАКТ:** нормализация не сошлась (max|mean Δφ'| > 1e-3), или m̂'-абляция > 0.40.
В этом случае вердикт не выносится, площадка бракуется.

## Оговорки (заранее)

1. Эксплораторное происхождение H1 (те же данные) → даже PASS-Т = кандидат; для снятия потолка
   SP_COMPLEX вероятно потребуется независимая реплика на второй площадке (SSVEP-JFPM, CANDIDATES.md).
2. RadioML 2016.10a имеет документированные «квирки» генерации (неконсистентные параметры
   модуляторов по классам). CFO-нормализация убирает самый грубый артефакт (mean Δφ), но другие
   систематики возможны.
3. Артефактом считается: (а) нормализация не сошлась; (б) m̂'-абляция классифицирует (>0.40);
   (в) иной скалярный канал объясняет TEST единственным числом (>0.70 при поле 0.333).
4. Статусы карточек НЕ меняются; потолок SP_COMPLEX двигает только автор по К1–К5.
