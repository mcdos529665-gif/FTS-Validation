# Пред-регистрация Д10 РЕАЛЬНОГО теста на RadioML 2016.10a (option Б)

Дата: 2026-07-09. Тип: **РЕАЛЬНЫЙ операциональный тест** (предметно документированная площадка,
§4 п.1) → при PASS даёт автору право двигать потолок SP_COMPLEX по К1–К5. Апарат (этот файл +
`run_radioml.py`) заморожен и коммитится **ДО загрузки реальных данных** — максимальная защита
от подглядывания: дизайн фиксирован прежде, чем виден хоть один реальный отсчёт.

## Гейт-апробации §3 (письменно)
1. Непрерывная фаза в ТЕСТ-модели? **ДА** — полный I/Q (`z=|z|·e^{iφ}`), `φ(t)` присутствует.
2. Таргет восстановим из одного `sign`? **НЕТ** — класс PSK-порядка = число точек созвездия на
   окружности (BPSK 2 / QPSK 4 / 8PSK 8); один бит полуплоскости порядок не задаёт.
3. Нужна ли `φ` тоньше полуплоскости? **ДА** — 8PSK vs QPSK требует разрешения угла `<< π`.

## Гипотезы
- **H1:** непрерывная фаза (полный I/Q) даёт предиктивную роль над тенью+битом
  `[|z(t)|, sign(Q(t))]` при РАВНОЙ ёмкости на различении const-modulus PSK-порядков.
- **H0:** роли нет / не воспроизводится / null догоняет уже при малой ёмкости.

## Данные и площадка
RadioML 2016.10a (DeepSig), публичный, I/Q `2×128`, 11 модуляций, SNR −20..18 dB.
- **РОТАЦИЯ (первичный):** `{BPSK, QPSK, 8PSK}` — const-modulus, `|z|` почти неинформативна.
- **КОНТРОЛЬ (§4 п.4):** `{PAM4, AM-DSB, AM-SSB}` — амплитуда несёт; фаза выигрывать не должна.
- `SNR>=10 dB` (чистый сигнал), потолок 2000 выборок/класс (CPU-бюджет). Всё заморожено.

Оговорка целостности: канонический хост DeepSig на момент сборки отдаёт **истёкший TLS-сертификат
и 502**; данные получит автор вручную или из зеркала (Kaggle). После загрузки — проверка формата
(11 модуляций, форма `(,2,128)`); официального SHA у DeepSig нет, целостность — по структуре.

## Представления (равная ёмкость)
- **TEST:** `[I(t); Q(t)]` → 256 признаков (полная непрерывная фаза).
- **NULL:** `[|z(t)|; sign(Q(t))]` → 256 признаков (тот же счёт; огибающая + бит полуплоскости,
  непрерывный аргумент выброшен) — shadow_lemma-объект (тень+бит).
- Модель: `MLPClassifier((hidden,), max_iter=300)`, ОДИНАКОВАЯ для обеих. StandardScaler на train.

## Свип по ёмкости (ЯДРО дизайна) — заморожен
`hidden ∈ {8, 16, 64, 256}`. Мотивация [внешнее, complex-NN литература]: вещественный/null
догоняет комплекс при росте ширины, ЕСЛИ информация у null есть, но требует ёмкости для
извлечения. Свип РАЗЛИЧАЕТ два исхода:
- **null НЕ догоняет** (`Δ>0` даже при `hidden=256`): фаза несёт то, чего у тени+бита НЕТ →
  роль НЕРЕДУЦИРУЕМА. Для const-modulus PSK это ожидаемый сильный исход (`|z|≈const`
  неинформативна, `sign(Q)` — лишь грубый бит; тонкий угол созвездия null недоступен).
- **null догоняет** (`Δ→0` к `hidden=256`): информация у null БЫЛА, не хватало ёмкости → фаза
  удобна, но не необходима → согласуется с ОВЕРЛЕЙНЫМ статусом (потолок стоит).
На КОНТРОЛЕ ожидается: test НЕ выигрывает (скорее null берёт амплитудные классы через `|z|`,
который test вычисляет нелинейно) — это и есть чистая специфичность (test не универсально лучше).

## Метрика и КРИТЕРИЙ (заморожены ДО прогона)
Метрика: accuracy, парный Wilcoxon (`test>null`, односторонний) по 20 фолдам (5×4).
Контроль ЧИСТ := test НЕ выигрывает значимо ни на одной ёмкости (`Δ<+0.03` ИЛИ `p>0.05`);
null, выигрывающий контроль, — ожидаемо и допустимо.
- **PASS (кандидат на снятие потолка):** на РОТАЦИИ `p<0.01` И медиана `Δacc>+0.03` на ВСЕХ
  ёмкостях свипа, ВКЛЮЧАЯ `hidden=256` (null НЕ догоняет → роль фазы нередуцируема); И контроль чист.
- **OVERLAY-СОГЛАСНО (потолок СТОИТ):** роль есть при `hidden=8` (`p<0.01`, `Δ>+0.03`), но к
  `hidden=256` `Δ<+0.03` или `p>=0.01` (null догнал) → фаза не необходима; контроль чист.
- **FAIL:** null не проигрывает даже при `hidden=8`, ИЛИ test выигрывает контроль (грязно).
- **ЧАСТИЧНО/UNCLEAR:** роль при малой ёмкости есть, но поведение по свипу неоднозначно, либо
  нестабильно. Во всех исходах, кроме PASS, потолок SP_COMPLEX НЕ двигается.

## Оговорки заранее (артефакты)
- **Утечка фазы в null** через ВРЕМЕННУ́Ю последовательность `sign(Q(t))` (нуль-пересечения
  кодируют переходы фазы). Если null неожиданно силён на PSK при малой ёмкости — проверить, не
  через бит-последовательность ли (это был бы Д11-канал, не Д10). Доп-проверка при подозрении:
  null с перемешанными по времени отсчётами (разрушает темпоральный фазовый след) как нижняя граница.
- **Неравная ёмкость:** счёт признаков одинаков (256), архитектура одна.
- Синтетика RadioML сгенерирована GNU Radio с реальными импейрментами — это документированная
  предметная площадка (§4 п.1), НЕ сконструированная нами под гипотезу (в отличие от pilot/).
