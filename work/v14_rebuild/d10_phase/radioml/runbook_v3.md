## 3. Дизайн v3 (точный; отступление = СТОП)

**CFO-нормализация (ключ v3).** Для каждого примера (z_t = I_t + i·Q_t, t=0..127):
1. Δφ_t = angle(z_{(t+1) mod 128} · conj(z_t));  m̂ = mean_t(Δφ_t).
2. Дероутация: z'_t = z_t · exp(−i · m̂ · t).
3. ВСЕ признаки ВСЕХ моделей строятся из z' (симметрия: артефакт вычтен у обеих сторон).
4. Машинная проверка нормализации: пересчитанный mean_t(Δφ'_t) по каждому примеру ≈ 0
   (|·| < 1e−6; assert в скрипте). Не сходится — СТОП.

**Модели (равная ёмкость: 256 признаков, одна MLPClassifier((hidden,), max_iter=300)):**
- TEST:   [|z'_t| (128); Δφ'_t (128)] — тень + непрерывные приращения фазы.
- NULL-A: [|z'_t|; sign(Q'_t)] — канонический тень+бит.
- NULL-B: [|z'_t|; sign(Δφ'_t)] — дифференциальный бит (сильнейший null).

**SCALARS-абляция (проверка «дешевизны», НЕ null для вердикта):** 10 признаков на пример:
std(Δφ'), mean(|Δφ'|), histogram(Δφ', bins=8, range=(−π,π], density). Оценивать при hidden=64.

**Задачи и замороженные параметры (унаследованы от v2, НЕ менять):**
РОТАЦИЯ {BPSK,QPSK,8PSK}; КОНТРОЛЬ {PAM4,AM-DSB,AM-SSB}; SNR≥10 (срезы 10..18 шаг 2);
cap 2000/класс; seed 20260709; hidden ∈ {8,16,64,256}; RepeatedStratifiedKFold(5,4)=20 фолдов;
StandardScaler fit на train; метрика accuracy; Wilcoxon односторонний test>null по фолдам.

**Гейт-апробации §3 runbook_complex_axis (ответь письменно в PREREGISTRATION_v3):**
(1) фаза ПОДАНА в TEST? (Δφ' явно — да); (2) таргет невосстановим из одного бита?;
(3) нужна ли θ тоньше полуплоскости? Любой неправильный ответ = СТОП.

## 4. Критерий (заморозить в PREREGISTRATION_v3 ДО прогона)

На РОТАЦИИ, против ОБОИХ null'ов (A и B): «победа на ёмкости h» := p<0.01 И медиана Δacc>+0.05.
- **PASS-Т (темпоральная роль):** победа на ВСЕХ h ∈ {8,16,64,256}; И TEST(h=64) −
  SCALARS ≥ +0.05 (парный Wilcoxon p<0.01); И контроль чист; И mean(Δφ')-абляция мертва
  (1 признак m̂' при h=16: acc < 0.40).
- **PASS-С (скалярная роль):** победа на всех h, контроль чист, НО TEST(64) − SCALARS < +0.05 —
  роль фазы есть, но исчерпывается распределительными статистиками. Для потолка слабее; так и писать.
- **OVERLAY-СОГЛАСНО:** победа при h=8, но хотя бы один null догоняет к h=256 → потолок стоит.
- **FAIL:** нет победы над обоими null'ами при h=8, или контроль грязен
  (контроль чист := на КОНТРОЛЕ test не превосходит НИ ОДИН null: медиана Δ<+0.03 ИЛИ p>0.05, все h).
- **АРТЕФАКТ:** нормализация не сошлась или новый скалярный канал классифицирует необъяснимо —
  СТОП, вердикт не выносить.
Наследуемая оговорка v2: H1 эксплораторного происхождения (те же данные) → даже PASS-Т =
кандидат; для снятия потолка SP_COMPLEX вероятно потребуется независимая реплика на второй площадке.
Статусы двигает ТОЛЬКО автор по К1–К5.
