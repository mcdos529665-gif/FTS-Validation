## 1. Критерий (гейт)

Канон [O_14, «Прирост определимости вопросов», candidate]:
> «Q_{n+1} невыразим ниже без скрытого аппарата. Если Q выражается ниже с той же
> ценой — основание падает.»

Операциональная форма (= «различающий ход», [clt_u6_note §4]):

> Чтение **R**, претендующее на **роль сверх переописания** нулевой гипотезы
> **X** (X = «это просто переописание/переименование»), **проходит QuestionGain
> ⟺ существует ход m** — предсказание / построение контрпримера / различение —
> **выводимый из R и НЕ воспроизводимый из X при РАВНОЙ цене**.
> Если каждый выход R реконструируем из X при равной цене ⇒ основание падает ⇒
> R = переописание (`analogy_only`), не уровень/роль.

Гейт (машинно, `probes.py::qg_gate`, свидетель **QG-1**):

    QG-pass(R | X) ⟺ (∃ ход m, выводимый из R) ∧ ¬(m воспроизводим из X при равной цене)

Ключевое звено — **«при равной цене»**: если X добирает ход m только ценой
скрытого аппарата (лишний параметр, гибкая модель, вручную вложенное знание) —
это НЕ равная цена, и R выигрывает. Наоборот, если гибкая модель на X дёшево
воспроизводит m — R проигрывает (ровно провал o20/D2 ниже).

### 1.1. Строгая конечная форма уточнения (2026-09-05)

Внешний исследовательский пакет EXPLICIT_ADDITIONS_2026-09-05.md уточняет этот
гейт только в области конечных представлений. Если текущая запись
\(q:\Omega\to C\) не выражает фиксированный вопрос \(r:\Omega\to D\), то
свидетель

\[
q(\omega_1)=q(\omega_2),\qquad r(\omega_1)\ne r(\omega_2)
\]

даёт строгий **информационный** свидетель QuestionGain. Полный гейт с ценой
требует дополнительного паспорта (§1.2). Совместная запись
\(q^+(\omega)=(q(\omega),r(\omega))\) минимальна по различимости среди всех
представлений, через которые факторизуются и \(q\), и \(r\): из
\(q=a\circ t,\ r=b\circ t\) следует \(q^+=(a,b)\circ t\) на образе \(t\).

Это усиливает **необходимую** часть QG-gate, но не заменяет его равную цену,
RoleNec или семантическую трассу. В частности, наличие такого \(r\) не выбирает
единственный следующий вопрос и не доказывает следующий рунг ФТС.

### 1.2. Паспорт проверки после основного DR-блока (2026-09-11)

[Внешнее: `e5_literature_review/dr_core_2026-09-11/REVIEW.md`, CR-01/09/14;
карточка O_14 остаётся candidate.] Для каждого применения зафиксировать:

1. Ω, нижнюю запись q, новый ответ r, доступные данные и контекст обеих сторон.
2. Вид утверждения: **информационное** `нет h:r=h∘q`; **языковое** — h
   исключён заданной грамматикой; **вычислительное** — h существует, но
   недоступен разрешённому декодеру в бюджете. Эти предикаты различаются.
3. Точность и кванторы: все состояния / почти наверное при указанной мере /
   ограниченный риск; единый декодер или семейство, зависящее от prior.
   Точечный контрпример на событии нулевой меры не доказывает положительный риск.
4. Нижнюю границу либо пару неразличимых состояний, верхнюю реализацию и цену
   получения r. В `(q,r)` нельзя считать дополнительный ответ бесплатным.
5. Общую модель цены: данные, подготовка/обучение, код, память, онлайн-операции,
   точность чисел, число повторений; одинаковое кэширование и примитивы.
   State-dependent advice — дополнительный вход. Разрешённая и оплаченная
   операция не становится «скрытой ФТС» только из-за похожего названия роли.
6. Независимый мост к конкретному переходу, RoleNec, допустимые конкуренты
   и условие поражения. Для O_07 отдельно проверяются промежуточные X.

Сохранение одного r не означает сохранения всех формул языка с операциями
(DRC-06). QG-1 остаётся калибровкой логики гейта; его булевы входы сами по себе
не доказывают невозможность реального декодера. Этот паспорт уточняет применение
O_14 и не меняет каноническую C(E) или C-NN.

## 2. Два отработанных инстанса (калибровка гейта)

- **Worked-NEGATIVE (форма D2/o20), свидетель QG-2.** R = «типизированное
  отсутствие 0_A / ветвь-знак» сверх null X = «плоский флаг ¬A / модуль |·|+контекст».
  Тест (sign/phase-retrieval, o20 и d2_sign, пред-регистрации): знак/типизация
  РЕКОНСТРУИРУЕМЫ из X при равной цене (гибкая модель: T3≈T2, Wilcoxon p=0.9995;
  информационная эквивалентность). ⇒ **QG-fail** ⇒ линия остаётся
  `candidate/analogy_only` (см. `work/REFUTED.md`). Проба QG-2: при данном `|a|`
  знак не различает целевую `y=f(|a|)` ⇒ хода нет.
- **Worked-POSITIVE (форма Марков–Некрасов), свидетель QG-3 (ср. CLT-5).**
  null X = «регулярность ⇒ независимость» (некрасовская склейка). Ход m =
  зависимая семья (lag-1 corr ≠ 0) с ТОЙ ЖЕ регулярностью (среднее сходится);
  X такое запрещает ⇒ m не воспроизводим ⇒ **QG-pass**. Существенно: тип хода
  (зависимая семья с той же регулярностью) ВЫВЕДЕН из типа ошибки (склейка
  «регулярность⇒независимость») — [clt_u6_note §3].

Гейт настроен так, что калибровочный минус падает, а плюс проходит.

## 4. Что закрывает / что остаётся

- **Закрывает** (для всей семьи разом): мета-вопрос «ПО КАКОМУ критерию судить
  роль-сверх-переописания?» — критерий формален, машинно-откалиброван (QG-1…3),
  грунтован в [O_14]. Для `oq-divorce-cases-genre` это и был весь вопрос (критерий
  засчитывания) ⇒ пункт → [~].
- **Не закрывает** (по-честному): критерий не выносит вердикт за каждый пункт —
  он даёт каждому тест-спецификацию. Вердикты `oq-synthesis`/`oq-fourier`/
  `oq-d4` — открыты; `oq-d2-half` и synthesis гейтованы E2 (сильная площадка
  phase/sign — «не гнать без площадки», o20/D2 при слабой уже дали QG-fail).
- **Дисциплина статуса**: прохождение гейта — необходимое, не достаточное; роль
  доказывается собственным свидетелем (К1–К5), не прохождением QG.
