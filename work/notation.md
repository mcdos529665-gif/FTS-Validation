# notation.md — словарь перегруженных символов ФТС

Здесь фиксируется СМЫСЛ обозначений ФТС, чтобы не подставлять общематематический.
При любом сомнении — это и `source/fts_cards.jsonl` главнее интуиции.

## Различения, которые нельзя смешивать
- `¬A`   — логическое отрицание моды A.
- `0_A`  — нулевая/пустая мода A (структурированное отсутствие), не отрицание.
- `−A`   — антимода A (антимода уровня), не фаза и не отрицание.
  → `¬A ≠ 0_A ≠ −A`.

## Кандидатная запись структурированного отсутствия
- Канон: `event(0_A)=¬A`, но обратный вывод `¬A→0_A` запрещён
  `[A2; OP_event0A]`.
- Исследовательская запись:
  `0_A^*(ℓ)=⟨A, ℓ, m, p, w⟩`, где `A` — ожидаемый тип, `ℓ` — локус,
  `m` — механизм отсутствия, `p` — provenance-цепочка, `w` — свидетельство.
- Звёздочка обязательна: это `candidate_typed_absence`, не новое каноническое
  определение `0_A`.
- `event`/`Tot` стирает `m,p,w`; одинаковая булева тень может иметь несколько
  несовместимых записей. Missing-indicator ближе к этой тени, а не к полной
  записи.
- `provenance ≠ mechanism`: путь обработки не доказывает причину; после
  `Sever` перенос оснований блокируется `[T7C; OP_Sever]`.

## Знаки минуса (нотация v14, paper §3.2a)
- `⊖F` (экспорт: `anti(F)`) — анти-форма формы F, оператор словаря Д1.
- `−`  — арифметический минус (знак числа на носителе).
- `Rot_θ F` (экспорт: `rot(theta,F)`) — фазовый поворот `e^{iθ}·F`, оператор Д10.
- `−A` — уровневая антимода 7+ (Ч-регистр), не математический знак.
  Теоремы связи: в ℝ `⊖F = −F` [C-01]; `Rot_π = ·(−1)` [C-38]; вещественный след
  фазовой орбиты = зеркальное окно `{F, ⊖F}` [C-39]. Как операторы структуры
  `⊖` (дискретный, Z/2) ≠ `Rot` (непрерывный, U(1)) — это и есть `phase ≠ −A`.

## Две границы лестницы (v14, paper §3.5–3.6)
- нулевая `x=0` (аддитивная единица): работает `⊖`, `F=⊖F ⟺ F=0` [C-01].
- единичная `x=1` (мультипликативная единица): работает `·`, `F·F=F` [C-49].
- вместе `{0,1}` = идемпотенты `x²=x` = бит. В `x=1` лестница У1–У9 → {+1,−1};
  6+ различимы только при `|x|∉{0,1}` (различение по масштабу); 3–5 — по знаку.

## Три регистра считывания (v14, paper §5.1b)
- аддитивный: разность `F−G`; формы встречаются в нуле (`F=⊖F ⟺ F=0`).
- модульный (Q-канал): `|·|`, `Q(z)=|z|²` — хранит величину, стирает ветвь/фазу [C-40].
- отношений (ratio-канал, Д11): `F/G`, экспорт `ratio(F,G)` — хранит ветвь
  (`x/|x|=sign(x)`), стирает величину; ноль — полюс, не граница; правые части
  всех уровней нормализуются к «отношение ≠ 1» [C-44…C-48].
  Комплексно: `z/|z| = e^{iθ}` — извлечение фазы; `z = |z|·(z/|z|)`.
  Лемма Tot: Tot = коллапс Z/2 → {1} (формализация О2).

## Уровни и окна
- `У(n)` (`U_n`) — уровень лестницы различимости; `U_m1` = У(−1) (шум/до-носитель).
- `window` — пятёрка соседних индексов уровня, напр. `(-1,0,1,2,3)`.
- carrier / pre-carrier — носитель различимости уровня.

## Кандидатная типизация Lift
- Канон: `X_{n+1}=Lift(X_n,Res_n)` и `π_n∘ι_n=id` `[A6; A7]`.
- Минимальный Set-кандидат:
  `L(X,R)=X×R`, `ι(x)=(x,r₀)`, `π(x,r)=x`, `ρ(x,r)=r`.
- Definability gain требует `∄q:X→R: ρ=q∘π`; при одноточечном `R` прироста нет.
- Конструкция требует непустого/pointed остатка. Канон базовую точку `r₀` не
  задаёт; это открытая предпосылка, а не разрешение выбрать её молча.
- `Lift_FTS(X,Res) ≠ lifting property (i ⟂ p)`. Связь с WFS требует отдельно
  задать категорию, факторизации всех морфизмов и диагональные заполнители.

## Регистры
- **М-регистр** — минимальная проекция выражения (`M_*`).
- **Ч-регистр** — частное/операциональное чтение (`CH_*`): Dist₃, Select, Agg, K, ...

## v11–v13 overlay (надстройки, НЕ канон уровней)
- v11: У7 = `Answer(W)=Close(W,W)` — акт закрытия ожидания ожиданием.
  κ/T7 — диагностический слой для агентных реализаций, не сущность уровня.
- v12: χ-лестница. `χ` = нормированный остаток ожидания; `χ*χ = χ² = Q(χ)` — сильный
  аналог У6. Верхние χ-формы — overlay/gate, не доказанная замена У7–У11.
- v13: комплексный overlay. `Q(z)=|z|²` прячет фазу (как вещественный квадрат прячет знак).
  У8+ получает вопрос о ветви/branch/sheet. **phase ≠ −A. branch access ≠ Lift.**
- Комплексные = скаляры с фазой/ветвью (полезны для 7–9). Тензоры = многоиндексные
  отношения/преобразования (для 10–12+). `array ≠ tensor` без закона преобразования.
