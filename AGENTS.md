# AGENTS.md

Основные инварианты ФТС, порядок чтения и работа с каноном задаются в
`PROJECT_INSTRUCTIONS.md`.

## Советующий гейт академического исследования

Перед утверждением внешнего основания не запускать поиск автоматически. Один раз за
смысловой инкремент советовать явный `$fts-academic-research`, если нужен prior art,
проверка ограниченной новизны, supporting/contradicting evidence, систематический
обзор, citation-network coverage или публикацию пытаются использовать для статуса ФТС.

Формат совета:

`Совет: здесь уместен $fts-academic-research, потому что <конкретный риск внешних оснований>. Для запуска укажите claim/OQ и режим quick|fact-check|lit-review|systematic-review.`

Не советовать этот навык для локальной проверки канона, редакторской правки,
экспорта, буквальной проверки файла или чисто математического claim. Внешние
источники остаются `[внешнее]`, не повышают `St_FTS` автоматически и не заменяют
основания канона. Во внешние сервисы по умолчанию передавать только поисковые
строки и библиографические метаданные.
